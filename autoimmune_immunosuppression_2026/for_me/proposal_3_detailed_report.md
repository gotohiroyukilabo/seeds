# Proposal 3 Detailed Report: Fc-silent or masked anti-OSMR

作成日: 2026-07-05

## 0. このレポートの目的

このレポートは、`outputs/seed_proposal_3.md` にまとめた「Fc-silent or masked anti-OSMR」について、基礎から理解するための補足資料である。

中心となる問いは以下である。

- OSMRとは何か
- なぜ免疫細胞ではなく組織側の受容体を狙うのか
- Fc-silentやmasked antibodyがなぜ重要なのか
- どこまで確認できればシーズとして前に進めるのか

## 1. まず超基礎: 免疫疾患の問題は免疫細胞だけではない

自己免疫疾患や慢性炎症疾患では、免疫細胞が暴走することが多い。

しかし、長引く病気では免疫細胞だけでなく、組織側の細胞も病態を維持するようになる。

例えば以下のような細胞である。

| 細胞 | 病態での役割 |
|---|---|
| 線維芽細胞 | コラーゲンや細胞外マトリックスを作り、線維化に関わる |
| 上皮細胞 | バリア、炎症シグナル、組織修復に関わる |
| ケラチノサイト | 皮膚炎症、かゆみ、バリア異常に関わる |
| 血管周囲細胞 | 血管障害や組織リモデリングに関わる |

つまり、病気が進むと「免疫細胞を抑える」だけではなく、「組織が炎症を維持する状態」を戻す必要がある。

## 2. OSMとは何か

OSMはOncostatin Mの略で、IL-6ファミリーに属するサイトカインである。

OSMは免疫細胞などから出て、線維芽細胞、上皮細胞、ケラチノサイトなどに作用する。

単純化すると、OSMは組織側の細胞に対して以下のようなメッセージを送る可能性がある。

```text
炎症を続ける
組織を作り替える
線維化方向に進める
バリアや修復反応を変える
```

この作用は病原体への反応や修復では有益な場合もある。しかし慢性炎症では、組織リモデリングや線維化を悪化させる可能性がある。

## 3. OSMRとは何か

OSMRはOSM receptorの略で、OSMを受け取る膜受容体である。

| 項目 | 内容 |
|---|---|
| タンパク質名 | OSM receptor / OSMR |
| UniProt ID | Q99650 |
| 種類 | 膜タンパク質 |
| 主な発現 | 線維芽細胞、上皮/皮膚系細胞など |
| 主な役割 | OSMシグナルを細胞内へ伝える |
| 抗体標的としての特徴 | 細胞表面にあり抗体がアクセスできる |

OSMRにOSMが結合すると、細胞内でSTAT3などのシグナルが動き、炎症性遺伝子や線維化関連遺伝子が変わる可能性がある。

```text
OSM
  ↓
OSMRを含む受容体複合体
  ↓
STAT3など
  ↓
炎症・線維化・組織リモデリング
```

## 4. なぜOSMRを狙うのか

多くの自己免疫薬は、免疫細胞やサイトカインを狙う。

OSMRを狙う発想は少し違う。病気の「組織側の実行部隊」を狙う。

| 従来の発想 | OSMRの発想 |
|---|---|
| 免疫細胞を抑える | 組織リモデリングを抑える |
| 炎症サイトカインを止める | 線維芽細胞/上皮細胞の病的反応を止める |
| 全身免疫抑制になりやすい | 組織病態に寄せられる可能性 |

このため、systemic sclerosisの皮膚線維化や、hidradenitis suppurativaのトンネル形成・慢性病変のような、組織構造の変化が大きい疾患で考える価値がある。

## 5. 想定疾患

## 5.1 Systemic sclerosis

systemic sclerosisでは、皮膚や肺などで線維化が進む。B細胞や炎症も関わるが、最終的な組織障害には線維芽細胞が大きく関わる。

OSMR-highの皮膚病変が存在し、OSMRを止めることで線維化マーカーが下がるなら、既存の免疫抑制とは違う切り口になる。

## 5.2 Hidradenitis suppurativa

HSは典型的な自己免疫疾患ではないが、慢性炎症、膿瘍、トンネル、瘢痕化が問題になる。TNF、IL-17、IL-1、IL-36など多くの免疫軸が試されているが、全患者を十分に制御できていない。

OSMRは、免疫反応そのものよりも、皮膚組織の慢性リモデリングに介入する仮説として考えられる。

## 6. Fc-silentとは何か

抗体のFc部分は、免疫細胞に「この標的を攻撃してよい」と伝えることがある。これによりADCCやCDCが起こる。

がんではこの作用が有利な場合がある。しかしOSMRでは、標的が線維芽細胞や上皮系細胞にも出る可能性がある。

そのため、OSMR陽性細胞を殺すのは危険である。

```text
やりたいこと:
OSMRシグナルを止める

やりたくないこと:
OSMRを持つ正常な線維芽細胞/上皮細胞を殺す
```

Fc-silent抗体は、Fcによる細胞傷害をできるだけ起こさない設計である。

## 7. Masked antibodyとは何か

masked antibodyは、通常の血中では抗原に結合しにくく、病変組織でマスクが外れて働くように設計する抗体である。

```text
血中/正常組織:
マスク付きで結合しにくい

炎症・線維化組織:
特定プロテアーゼでマスクが切れる
  ↓
抗体がOSMRに結合できる
```

OSMRは組織修復にも関わる可能性があるため、全身で強く止めると創傷治癒や上皮修復に悪影響が出るかもしれない。masked designは、その安全域を広げるためのバックアップ案である。

## 8. 既存薬との差別化

| 既存/競合 | 課題 | 本提案の差別化仮説 |
|---|---|---|
| TNF/IL-17阻害 | 炎症は抑えるが組織リモデリングが残ることがある | 組織側の病的反応を抑える |
| B細胞標的 | 自己免疫側には効くが線維芽細胞へは間接的 | 線維化実行細胞へ近い |
| IL-6R阻害 | 既に競合が多い | OSMRはより組織リモデリング寄り |
| 抗線維化小分子 | 疾患全体の免疫病態には弱い可能性 | 炎症と組織反応の接点を狙う |

## 9. 主なリスク

| リスク | 内容 |
|---|---|
| 因果性 | OSMRが病気の原因ではなく、炎症の結果として上がっているだけかもしれない |
| 安全性 | 創傷治癒、上皮修復、バリア機能を損なう可能性 |
| 患者選択 | OSMR-high患者をどう定義するか |
| translational risk | 動物モデルがヒト病態を反映しにくい可能性 |
| developability | 受容体複合体、エピトープ、species cross-reactivityが難しい |

## 10. 最初にやるべき検証

OSMRは臨床的に十分de-riskされていないため、最初はヒト病変組織で勝負するべきである。

| 実験 | 見たいこと |
|---|---|
| single-cell RNA-seq / spatial解析 | OSMRがどの細胞に出ているか |
| OSM刺激線維芽細胞 assay | 抗体で炎症・線維化マーカーが下がるか |
| keratinocyte assay | 皮膚炎症/バリア関連シグナルが抑えられるか |
| SSc/HS explant | 実病変組織で戻るシグナルがあるか |
| wound scratch assay | 創傷治癒を強く邪魔しないか |
| masked activation assay | 病変組織でだけマスクが外れるか |

## 11. Go / No-Go

Go条件:

- OSMR-highの患者病変サブグループが明確
- OSMR blockadeでヒト病変由来細胞/組織の炎症・線維化指標が下がる
- 正常組織修復への悪影響が許容範囲
- Fc-silentで十分、またはmasked designで安全域を広げられる

No-Go条件:

- OSMR発現はあるが、止めても病態指標が動かない
- 正常な創傷治癒や上皮修復を強く阻害する
- 病変選択的なbiomarkerやmask activationが作れない
- 受容体複合体の薬理が複雑すぎ、再現性ある阻害抗体が作れない

## 12. 最終コメント

この提案は、3件の中で最も探索色が強い。臨床的に十分証明された標的ではないが、免疫細胞ではなく組織リモデリングを狙う点に新規性がある。

成功すれば、自己免疫疾患を「免疫抑制」だけでなく「病的組織反応の解除」として捉えるシーズになる。一方で、最初の実験でヒト病変組織に明確な作用が出なければ、早めに止めるべき候補でもある。

## 13. もう一段深い背景: tissue remodelingを標的にする意味

自己免疫疾患の治療では、伝統的に免疫細胞や炎症性サイトカインを狙ってきた。

しかし、慢性疾患では、炎症が単に免疫細胞の中だけで完結しているわけではない。組織側の細胞が病的な状態に固定され、炎症を維持したり、線維化や瘢痕を進めたりする。

この状態を、ここではtissue remodelingと呼ぶ。

```text
免疫細胞が炎症を起こす
  ↓
組織細胞が活性化する
  ↓
組織細胞がさらに炎症性シグナルを出す
  ↓
線維化・肥厚・瘢痕・バリア異常が進む
  ↓
免疫細胞がさらに集まる
```

このループに入ると、免疫細胞だけを抑えても、組織側の異常が残ることがある。

OSMR提案の意義は、この組織側ループに介入する点にある。

## 14. OSM/OSMR axisをもう少し詳しく見る

OSMはIL-6 family cytokineの一つである。IL-6ファミリーのサイトカインは、炎症、細胞増殖、分化、組織修復に関係する。

OSMは受容体複合体を介してシグナルを伝える。OSMRはその重要な構成要素である。

OSM/OSMR刺激で動きうる下流は以下。

| 下流/反応 | 意味 |
|---|---|
| STAT3 signaling | 炎症性遺伝子、細胞生存、組織反応 |
| MAPK pathway | 細胞活性化、増殖、ストレス応答 |
| 炎症性サイトカイン | IL-6、CXCL chemokinesなどの誘導可能性 |
| ECM remodeling | コラーゲン、MMP、fibronectinなど |
| epithelial response | バリア、分化、修復反応の変化 |

このように、OSMRは単純な「炎症サイトカイン受容体」ではなく、組織細胞の状態を変える受容体として考えた方がよい。

## 15. なぜOSMそのものではなくOSMRなのか

OSM ligandを中和する方法と、OSMR receptorをブロックする方法がある。

| アプローチ | 長所 | 短所 |
|---|---|---|
| anti-OSM | ligandを直接中和できる | OSM濃度/局所産生に左右される |
| anti-OSMR | 受容体側でシグナルを止める | OSMRの正常機能も止める |
| downstream阻害 | STAT3などを抑える | 選択性が低くなりやすい |

OSMRを狙う利点は、病変組織でOSMR陽性細胞が病態実行細胞であれば、そこに直接介入できる点である。

一方で、OSMRは正常な修復にも関係する可能性があるため、受容体を止める方が安全性リスクは大きいかもしれない。

このため、Fc-silentやmasked designが重要になる。

## 16. Systemic sclerosisでの仮説

SScでは、皮膚や肺で線維化が進む。線維芽細胞は病態の実行役である。

OSMR仮説をSScに当てると、以下のようになる。

```text
免疫細胞/炎症環境
  ↓ OSM
OSMR陽性線維芽細胞
  ↓
炎症性・線維化性プログラム
  ↓
皮膚硬化、肺線維化、組織機能低下
```

この仮説が正しければ、OSMRを止めることで、線維芽細胞の病的活性化を下げられる可能性がある。

ただし、SScは非常に複雑である。血管障害、自己抗体、B細胞、T細胞、線維芽細胞、上皮障害が絡む。OSMRだけで疾患全体を止められるとは考えにくい。

したがって、狙うべきは「OSMR-highで、組織リモデリングが現在進行形の患者」である。

## 17. HSでの仮説

HSでは、毛包周囲の炎症、膿瘍、瘻孔/トンネル、瘢痕化が問題になる。

既存のTNF阻害やIL-17阻害で改善する患者はいるが、トンネルや慢性病変が残ることがある。

OSMR仮説では、HSの慢性病変を以下のように見る。

```text
慢性炎症
  ↓
ケラチノサイト/線維芽細胞/上皮系細胞の病的活性化
  ↓
組織破壊と修復異常
  ↓
トンネル形成・瘢痕化
```

もしOSM/OSMRがこの慢性リモデリングを維持しているなら、OSMR blockadeは単なる炎症抑制とは異なる薬効を持てる。

ただしHSは細菌叢、毛包閉塞、機械的刺激、肥満、喫煙なども絡む。OSMRだけで全体を説明しない方がよい。

## 18. OSMR-high患者をどう見つけるか

OSMR提案の成否は、患者選択にかなり依存する。

考えられる選択方法は以下。

| 方法 | 内容 | 長所 | 弱点 |
|---|---|---|---|
| lesional RNA | 病変組織でOSMR/OSM signatureを見る | 病態に近い | 生検が必要 |
| single-cell RNA-seq | どの細胞がOSMRを出すか分かる | 解像度が高い | 開発実務では重い |
| spatial transcriptomics | OSMR陽性細胞の位置が分かる | 組織文脈が見える | コストと解析が重い |
| IHC/ISH | 臨床検査化しやすい | 空間情報あり | 抗体/プローブ品質が重要 |
| serum OSM | 採血で簡単 | 組織OSMR活性を反映しない可能性 |
| downstream signature | STAT3/CXCL/ECM遺伝子群を見る | 機能に近い | OSMR特異性は低い |

理想は、OSMR発現だけでなく、OSM stimulation signatureも同時に見ることである。

```text
OSMRが出ている
  +
OSM下流シグナルが動いている
  +
抗OSMRでそのシグナルが戻る
```

この3点がそろえば、標的妥当性がかなり強くなる。

## 19. Fc-silent設計を深掘りする

OSMRは病的細胞だけでなく、正常な線維芽細胞や上皮細胞にも出る可能性がある。

そのため、抗体のFc effector functionでOSMR陽性細胞を殺すと危険である。

想定される悪いシナリオ:

```text
抗OSMR抗体が正常線維芽細胞に結合
  ↓
NK細胞や補体が反応
  ↓
正常組織細胞が傷害される
  ↓
創傷治癒や組織維持に悪影響
```

したがって、最初からFc-silentを基本設計にするべきである。

Fc-silentで確認すべきこと:

- FcγRI、FcγRIIA、FcγRIIB、FcγRIIIAへの結合低下
- C1q結合低下
- ADCCなし
- CDCなし
- FcRn結合は維持して半減期を保つ
- Fc改変による物性悪化がない

ここで大事なのは、Fcを完全に無意味にするのではなく、「effector functionは消し、PKに必要なFcRn機能は残す」ことである。

## 20. Masked antibodyを深掘りする

masked antibodyは、OSMRのように正常組織にも出る標的で特に意味がある。

設計イメージ:

```text
抗体の抗原結合部位にmask peptideを付ける
  ↓
正常血中ではOSMRに結合しにくい
  ↓
炎症/線維化組織に多いproteaseでmaskが切れる
  ↓
抗体がOSMRに結合し、シグナルを止める
```

ただしmasked antibodyは難しい。

| 論点 | 内容 |
|---|---|
| Maskが弱すぎる | 血中でも結合してしまい、安全性メリットが消える |
| Maskが強すぎる | 病変組織でも活性化後の結合が弱い |
| Protease選択 | 病変で高く、正常で低いproteaseが必要 |
| 活性化部位 | 本当に標的細胞近傍でmaskが外れるか |
| CMC | 分子が複雑になり物性が悪くなる可能性 |
| 評価系 | in vitroで良くてもヒト組織で再現しない可能性 |

したがって、masked antibodyは最初から本命にするというより、Fc-silent blocking antibodyで有効性が見えたが正常組織安全性が狭い場合の拡張案とするのが現実的である。

## 21. ADCがなぜ不向きか

OSMRは膜タンパク質なので、形式上はADCも作れるかもしれない。

しかし自己免疫/線維化疾患では、ADCはかなり不向きである。

理由:

- OSMRは正常構造細胞にも発現する可能性がある。
- payloadで線維芽細胞や上皮細胞を殺すと修復障害が起こる。
- 慢性疾患で細胞毒性payloadを繰り返し使うのは安全性が厳しい。
- pathologic fibroblastだけに選択的に入る保証がない。

例外的に、病的線維芽細胞に極めて限定的な発現と選択的internalizationが示されれば議論できるが、現時点では初期シーズとして推奨しない。

## 22. Safety windowをどう作るか

OSMRの安全性評価では、免疫抑制よりも組織修復を重視する。

| 安全性評価 | 見るべきこと |
|---|---|
| wound scratch assay | ケラチノサイト/線維芽細胞の移動と修復が止まりすぎないか |
| 3D skin model | 表皮分化、バリア、炎症反応への影響 |
| lung epithelial repair assay | 肺上皮修復への影響 |
| fibroblast viability | 細胞を殺していないか |
| infection/barrier model | バリア防御を弱めないか |
| cytokine release | OSMR陽性細胞や免疫細胞で過剰反応がないか |

薬効側では、線維化マーカーが下がることを見たい。

安全側では、正常修復が完全には止まらないことを見たい。

このバランスがOSMRのtherapeutic windowである。

## 23. Developability上の論点

OSMR抗体では、標的が膜受容体であるため、以下の点を初期から見るべきである。

| 論点 | 内容 |
|---|---|
| Epitope | ligand bindingを止めるのか、受容体複合体形成を止めるのか |
| Internalization | 受容体が内在化するか。blockingなら過度な内在化は不要 |
| Species cross-reactivity | cynomolgusで薬理・毒性を見られるか |
| Agonism | 抗体が逆に受容体を活性化しないか |
| Fc silence | 構造細胞傷害を避ける |
| Tissue penetration | 皮膚/線維化組織に十分届くか |
| Biomarker assay | OSMR/OSM signatureを臨床で測れるか |

特に危険なのは、抗体がblockingではなくagonisticに働くこと。OSMRを刺激してしまう抗体は、病態を悪化させる可能性がある。

したがって、binding assayだけでなく、functional antagonist assayを最初から置く必要がある。

## 24. 推奨する初期研究パッケージ

## 24.1 0-3か月: ヒト病変データで標的妥当性を見る

- SSc皮膚、SSc-ILD、HS病変の公開single-cellデータを確認する。
- OSMR発現細胞を同定する。
- OSM ligandや下流STAT3/CXCL/ECM signatureが同じ病変にあるか確認する。
- 正常皮膚・肺・腸などでのOSMR発現も確認する。

## 24.2 3-6か月: ex vivo機能評価

- OSM刺激ヒト線維芽細胞でCOL1A1、ACTA2、FN1、IL6、CXCL8などを見る。
- ケラチノサイト/上皮細胞で炎症・バリア遺伝子を見る。
- SSc/HS患者組織 explantで抗OSMRが病態signatureを戻すか確認する。
- 抗体がagonistになっていないか確認する。

## 24.3 6-12か月: 分子設計と安全性

- Fc-silent IgGの候補を作る。
- ADCC/CDCがないことを確認する。
- wound healing/epithelial repairへの影響を見る。
- safety marginが狭い場合、masked antibodyのprotease条件を探索する。
- cynomolgus cross-reactivityがなければ代替tox戦略を考える。

## 25. 社内提案での一言

この候補は「免疫細胞をさらに叩く薬」ではなく、「慢性炎症で病的状態になった組織細胞を正常側へ戻す薬」と説明すると分かりやすい。

強み:

- 新規性が高い
- 競合が比較的少ない
- tissue remodelingという未充足領域に入れる
- Fc-silent/maskedなど抗体工学の意味がある

弱み:

- 臨床de-riskが弱い
- OSMRがdriverか不明
- 正常修復阻害リスクがある
- biomarkerが未成熟

したがって、OSMRは「大きな賭け」ではなく、「早期にヒト組織で白黒をつける探索シーズ」として扱うのがよい。

## 26. 最終的な判断軸

OSMRを進めるかどうかは、最終的には以下の問いに答えられるかで決まる。

1. 病変組織にOSMR-highの患者群がいるか。
2. OSMRは単なるmarkerではなく、病的遺伝子プログラムを動かしているか。
3. 抗体でそのプログラムを戻せるか。
4. 正常な創傷治癒や上皮修復を止めすぎないか。
5. Fc-silentまたはmasked設計で安全域を作れるか。

この5つのうち、1-3が崩れるならbiologyとしてNo-Go。4-5が崩れるならmodalityとしてNo-Goである。
