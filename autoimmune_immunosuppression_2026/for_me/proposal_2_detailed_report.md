# Proposal 2 Detailed Report: pH-recycling anti-CCL24

作成日: 2026-07-05

## 0. このレポートの目的

このレポートは、`outputs/seed_proposal_2.md` にまとめた「pH-recycling anti-CCL24」について、基礎から理解するための補足資料である。

中心となる問いは以下である。

- CCL24とは何か
- なぜsystemic sclerosisやPSCのような線維化疾患で考えるのか
- pH-dependent recycling antibodyとは何か
- どの条件なら新規シーズとして進める価値があるのか

## 1. まず超基礎: 炎症と線維化

自己免疫疾患では、免疫細胞が組織に集まり、炎症が続くことがある。

炎症が長引くと、組織修復の仕組みが過剰に働き、線維化が起こる。

```text
免疫細胞が集まる
  ↓
炎症性サイトカイン・ケモカインが出る
  ↓
線維芽細胞が活性化する
  ↓
コラーゲンなどの細胞外マトリックスが増える
  ↓
組織が硬くなる・機能が落ちる
```

systemic sclerosisでは皮膚や肺などが硬くなる。PSCでは胆管周囲の炎症と線維化が進む。どちらも、単に免疫を抑えるだけでは十分に戻らないことが多い。

## 2. ケモカインとは何か

ケモカインは、免疫細胞を呼び寄せる小さなタンパク質である。

イメージとしては、免疫細胞に対する「集合場所の案内」である。

```text
炎症組織がケモカインを出す
  ↓
免疫細胞がその濃度勾配に沿って移動する
  ↓
炎症組織に集まる
```

ケモカインは種類が多く、冗長性がある。つまり1つを止めても、別のケモカインが代わりに働く可能性がある。これはCCL24を狙うときの大きなリスクである。

## 3. CCL24とは何か

CCL24は、eotaxin-2とも呼ばれる分泌タンパク質である。

| 項目 | 内容 |
|---|---|
| タンパク質名 | CCL24 / eotaxin-2 |
| UniProt ID | O00175 |
| 種類 | 分泌型ケモカイン |
| 主な受容体 | CCR3 |
| 関わる細胞 | 好酸球、単球/マクロファージ系、線維化関連細胞との関係が示唆 |
| 抗体標的としての特徴 | 細胞外にあるため中和しやすい |

CCL24が多いと、CCR3を持つ細胞が炎症組織へ集まりやすくなる可能性がある。さらに、炎症と線維化をつなぐ軸として注目されている。

## 4. なぜsystemic sclerosisなのか

systemic sclerosisは、自己免疫、血管障害、線維化が絡み合う疾患である。

現実的な課題は以下である。

- 皮膚硬化を十分に戻せる治療が限られる
- ILD進行を止めきれない患者がいる
- ステロイドは腎クリーゼなどの懸念から使いにくい
- MMF、cyclophosphamide、rituximab、tocilizumab、nintedanibなどを使っても十分でない患者がいる

CCL24を狙う仮説は、「免疫細胞の動員」と「線維芽細胞活性化」の間を切ることである。

## 5. なぜPSCも考えるのか

PSCはprimary sclerosing cholangitisの略で、胆管に炎症と線維化が起こる疾患である。現時点で疾患修飾的な標準治療が乏しい。

PSCは自己免疫そのものというより、免疫・胆管障害・線維化が絡む疾患である。CCL24のような炎症線維化ケモカインは、PSCでも仮説が立つ。

ただし、PSCは臨床試験のエンドポイントが難しい。ALP、MRCP、肝線維化、イベント抑制など、どの指標で早期PoCを見るかが課題になる。

## 6. 既存の臨床開発: CM-101

CCL24では、CM-101という抗CCL24抗体の開発がある。

ClinicalTrials.gov確認では以下が重要である。

- PSC phase 2: 完了
- systemic sclerosis phase 2: suspended

ここで重要なのは、suspendedの理由がこの調査だけでは不明であること。

可能性としては以下がある。

| 可能性 | 意味 |
|---|---|
| 有効性不足 | CCL24単独では不十分かもしれない |
| 安全性 | class riskがあるかもしれない |
| 事業判断 | 必ずしも標的失敗とは限らない |
| 登録/運営 | 希少疾患試験の実行難度かもしれない |
| 資金/優先順位 | 会社側の事情かもしれない |

したがって、CM-101の公開データと中止・停止理由の確認は必須である。

## 7. pH-dependent recycling antibodyとは何か

普通の抗体は、抗原に結合して体内を循環し、細胞に取り込まれると一緒に分解されることがある。

pH-dependent recycling antibodyは、pHの違いを使って抗体を再利用しやすくする設計である。

```text
血中/組織: pHほぼ中性
  ↓
抗体がCCL24に結合
  ↓
細胞内エンドソーム: pHが酸性
  ↓
抗体がCCL24を離す
  ↓
抗体はリサイクルされ、CCL24は分解へ
```

この設計の狙いは、抗体1分子が何度もCCL24を捕まえられるようにすることである。

CCL24のような分泌タンパク質では、抗原量が多いと抗体が消費されやすい。pH-dependent recyclingは、その抗原シンク問題に対する差別化案になる。

## 8. 既存薬との差別化

| 既存/競合 | 課題 | 本提案の差別化仮説 |
|---|---|---|
| IL-6R阻害 | 炎症には効くが線維化への効果は限定的な場合 | 炎症線維化ケモカインを直接狙う |
| B細胞標的 | 自己免疫側には効くが線維芽細胞軸は間接的 | 線維化関連の細胞動員を狙う |
| nintedanib | ILD進行抑制であり免疫疾患全体の制御ではない | 免疫・線維化の接続点を狙う |
| 通常の抗CCL24 | 抗原シンクで用量が重くなる可能性 | pH recyclingでPK/PDを改善する |

## 9. 主なリスク

| リスク | 内容 |
|---|---|
| 冗長性 | 他のケモカインが代わりに働く可能性 |
| 因果性 | CCL24が原因ではなく結果である可能性 |
| 臨床試験 | SSc/PSCはエンドポイントが遅い |
| 競合情報 | CM-101の停止理由が不明 |
| developability | pH依存性を入れると親和性・安定性が難しくなる |

## 10. 最初にやるべき検証

この標的は、ヒト疾患組織での確認が特に重要である。

| 実験 | 見たいこと |
|---|---|
| SSc/PSC血清でCCL24測定 | CCL24-high患者が存在するか |
| 組織染色/空間解析 | CCL24が病変部位にあるか |
| CCR3 chemotaxis assay | 抗体で細胞遊走を止められるか |
| fibroblast co-culture | 線維化マーカーが下がるか |
| pH binding assay | 中性で結合、酸性で解離するか |
| antigen clearance model | 通常IgGよりPK/PDが良いか |

## 11. Go / No-Go

Go条件:

- CCL24-highの患者サブグループが明確にある
- CCL24中和で患者由来細胞/組織の線維化・炎症指標が下がる
- pH-dependent recyclingで通常抗体よりPK/PDが改善する
- CM-101の懸念が設計や患者選択で回避可能

No-Go条件:

- CCL24が上がっているだけで機能的な意味がない
- 他のケモカイン冗長性で効果が消える
- CM-101の停止理由がclass-limiting safetyまたは明確な有効性失敗
- pH依存設計で中和活性や物性が崩れる

## 12. 最終コメント

この提案は、3件の中で最も「線維化に新しい切り口を出す」候補である。B細胞やIFNのような混雑した自己免疫軸から少し外れ、炎症と線維化をつなぐケモカインを狙う。

ただし、魅力と同じくらい不確実性もある。特にCCL24が本当にdriverなのか、CM-101の臨床状況をどう解釈するかが最大の論点である。

## 13. もう一段深い背景: なぜ線維化は難しいのか

線維化疾患の難しさは、炎症を止めても線維化が戻るとは限らない点にある。

炎症が始まり、その結果として線維芽細胞が活性化し、コラーゲンや細胞外マトリックスが蓄積する。この状態が長く続くと、組織構造そのものが変わる。

```text
初期:
炎症が強い
  ↓
免疫抑制で戻る余地がある

中期:
炎症 + 線維芽細胞活性化
  ↓
免疫と線維化の両方を止める必要

後期:
線維化・瘢痕化が固定
  ↓
炎症を止めても機能回復しにくい
```

したがって、CCL24を狙うなら、患者選択は「線維化がある患者」では不十分である。「まだ炎症線維化軸が動いていて、介入すれば戻せる患者」を見つける必要がある。

## 14. CCL24がdriverかmarkerか

CCL24提案で最も重要な生物学的問いは、CCL24がdriverなのかmarkerなのかである。

| 立場 | 意味 | 開発上の示唆 |
|---|---|---|
| Driver | CCL24が病態を進めている | 中和抗体で病態を変えられる可能性 |
| Marker | 炎症の結果として上がっているだけ | 中和しても臨床効果は弱い可能性 |
| Amplifier | 単独原因ではないが病態を増幅 | 併用/患者選択で有効な可能性 |

現実的には、CCL24が単独driverである可能性よりも、amplifierである可能性を考える方が自然である。

この場合、薬効を見るには、CCL24が高いだけでなく、CCL24に依存した細胞遊走や線維芽細胞活性化が実際に起きていることを示す必要がある。

## 15. CCL24-high患者をどう定義するか

この提案では、バイオマーカー戦略が非常に重要である。

CCL24-highを定義する候補は以下。

| バイオマーカー | 意味 | 注意点 |
|---|---|---|
| 血清CCL24 | 測定しやすい | 組織病変を反映しない可能性 |
| 病変組織CCL24 mRNA | 局所病態に近い | 生検が必要 |
| CCL24 protein IHC/ISH | 空間情報が得られる | 抗体/プローブ品質が重要 |
| CCR3陽性細胞浸潤 | CCL24応答細胞の存在 | 他のCCR3 ligandsの影響も受ける |
| 好酸球数 | 簡便 | CCL24特異性は低い |
| fibrosis transcriptome | 線維化活性を反映 | CCL24との因果関係は別途必要 |

最も説得力があるのは、単一バイオマーカーではなく、以下のような組み合わせである。

```text
血清CCL24高値
  +
病変組織でCCL24/CCR3軸が活性
  +
線維化transcriptomeが動いている
  +
抗CCL24でex vivo反応が戻る
```

## 16. Systemic sclerosisで狙うべき患者

SSc全体を対象にすると、病態が広すぎる。

狙うなら、以下のような患者がよい。

| 患者像 | 理由 |
|---|---|
| 早期diffuse cutaneous SSc | まだ可逆性がある可能性 |
| mRSSが進行中 | 変化を評価しやすい |
| inflammatory skin signatureあり | 免疫線維化介入が効きやすい可能性 |
| CCL24高値 | 標的依存性を示しやすい |
| ILD進行リスクあり | unmet needが大きい |
| 過度な末期線維化ではない | 戻せる余地がある |

逆に、長期罹患で線維化が固定し、炎症シグナルが低い患者は、CCL24抗体の薬効が見えにくい可能性がある。

## 17. PSCで狙うべき患者

PSCでは、胆管炎症と線維化が問題になる。臨床試験が難しい理由は、疾患進行が遅く、短期間でイベントを評価しにくいことである。

初期PoCでは、臨床イベントではなく、以下のような中間指標が必要になる。

| 指標 | 長所 | 限界 |
|---|---|---|
| ALP | 使いやすい | 真の予後代替として完全ではない |
| GGT | 胆道障害を反映 | 変動がある |
| ELF score | 線維化との関連 | CCL24特異性はない |
| MRCP | 胆管画像 | 変化が遅い |
| liver stiffness | 非侵襲的 | 炎症でも変わる |
| serum CCL24 | 標的近接 | 臨床効果との関係は要検証 |

PSCでの勝ち筋は、CCL24-highかつ炎症線維化が動いている患者に絞り、短期で標的 engagementと線維化関連PDが動くことを示すことである。

## 18. なぜpH-recyclingが差別化になるのか

分泌タンパク質を抗体で中和するとき、しばしば問題になるのがantigen sinkである。

抗原が大量にあると、抗体がどんどん抗原に結合し、複合体として処理され、必要量が増える。

pH-recycling antibodyでは、抗体が抗原を捕まえたあと、酸性環境で抗原を離し、抗体だけが再利用されることを狙う。

もう少し詳しく書くと、以下の流れになる。

```text
1. 血中や組織で抗体がCCL24に結合する
2. 抗体-CCL24複合体が細胞に取り込まれる
3. エンドソーム内は酸性pHになる
4. 抗体がCCL24を離す
5. CCL24は分解へ向かう
6. 抗体はFcRn経由で血中に戻る
7. 同じ抗体が再びCCL24を捕まえる
```

これにより、通常抗体より少ない投与量で同じPD効果を出せる可能性がある。

ただし、pH依存性を入れると、中性pHでの結合力、酸性pHでの解離、熱安定性、凝集、製造性のバランスが難しくなる。

## 19. Bispecific化はいつ考えるべきか

CCL24単独で効かないリスクは、ケモカイン冗長性である。

例えばCCL11、CCL26、CCL2、CXCL系など、他の走化性因子が代替する可能性がある。

では最初からbispecificにすべきかというと、必ずしもそうではない。

| 方針 | 長所 | 短所 |
|---|---|---|
| CCL24単独 | シンプル、開発しやすい | 冗長性に弱い |
| CCL24 x 他ケモカイン | 冗長性を潰せる可能性 | 安全性・CMC・固定比率が難しい |
| CCL24 x fibrosis mediator | 線維化に深く入れる可能性 | biologyが複雑 |
| 併用療法 | 用量調整しやすい | 開発コスト・臨床設計が重い |

推奨は、最初はCCL24単独でヒト組織依存性を確認し、冗長性が明確ならbispecificを考えること。

最初からbispecificにすると、失敗したときに「CCL24が悪いのか」「相手標的が悪いのか」「formatが悪いのか」が分からなくなる。

## 20. Safety windowの考え方

CCL24は免疫細胞の移動に関わるため、完全に無害ではない。

主な安全性論点は以下。

| 論点 | 内容 | 初期評価 |
|---|---|---|
| 好酸球機能 | 寄生虫防御やアレルギー反応への影響 | 好酸球遊走/活性化 assay |
| 感染 | 特定免疫細胞動員の低下 | 感染既往/免疫応答モデル |
| 組織修復 | 線維化抑制が修復阻害になる可能性 | wound/fibrosis balance assay |
| 免疫複合体 | soluble antigenとの複合体形成 | immune complex/FcγR assay |
| 長期投与 | 慢性疾患での持続抑制 | repeat-dose tox計画 |

一般に、CCL24はB細胞除去やCD40L blockadeより安全域が広い可能性がある。しかし、それは仮説であって、好酸球・組織修復・感染の観点で確認が必要である。

## 21. CM-101から何を学ぶべきか

CM-101はこの提案にとって、追い風でもあり向かい風でもある。

追い風:

- CCL24を抗体で狙う臨床開発の前例がある。
- PSC/SScという疾患選択の妥当性を示唆する。
- 標的が完全に未踏ではないため、投資説明がしやすい。

向かい風:

- 先行品があるため、新規性は下がる。
- SSc試験のsuspended理由が不明。
- もし有効性不足や安全性で止まっているなら、同じ落とし穴に落ちる。

確認すべきこと:

- SSc試験のsuspended理由
- PSC phase 2の主要/副次評価項目
- CCL24低下や下流PDが見えたか
- safety signalの有無
- 用量と標的占有の関係
- biomarker enrichmentをしていたか

## 22. 推奨する初期研究パッケージ

## 22.1 0-3か月: public dataとサンプルで仮説確認

- SSc皮膚、SSc-ILD、PSC肝/胆管データでCCL24発現を確認する。
- CCL24発現細胞とCCR3陽性応答細胞をsingle-cell/空間情報で見る。
- CCL24-highが疾患重症度や進行と関係するか調べる。

## 22.2 3-6か月: function確認

- CCL24中和でCCR3陽性細胞の遊走が止まるか。
- 患者血清や組織抽出液による遊走が抗CCL24でどの程度戻るか。
- 線維芽細胞co-cultureでCOL1A1、ACTA2、FN1、炎症性サイトカインが下がるか。
- CCL24単独刺激だけでなく、疾患環境に近い複合刺激で見る。

## 22.3 6-12か月: 抗体工学

- 通常中和抗体とpH-dependent候補を比較する。
- pH 7.4で強く結合し、pH 5.5-6.0で解離する候補を選ぶ。
- FcRn recycling、抗原clearance、凝集、熱安定性を確認する。
- 低用量でPDが維持できるかモデル化する。

## 23. 社内提案での一言

この候補は「免疫細胞を広く抑える薬」ではなく、「炎症と線維化をつなぐケモカインの流れを断ち、pH-recyclingで実用的な中和抗体にする」提案である。

ただし、最大の論点はCCL24が本当に病態を動かしているかである。

提案時には、以下をはっきり言うのがよい。

- CCL24-high患者に絞る
- ヒト組織で機能依存性を見る
- CM-101の臨床履歴を必ず精査する
- pH-recyclingは「おまけ」ではなく、soluble chemokine標的の差別化コアである

この4点が立てば、線維化領域の新規抗体シーズとして検討する価値がある。
