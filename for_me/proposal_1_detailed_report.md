# Proposal 1 Detailed Report: BAFF-R選択的B細胞制御抗体

作成日: 2026-07-05

## 0. このレポートの目的

このレポートは、`outputs/seed_proposal_1.md` にまとめた「BAFF-R選択的B細胞制御抗体」について、基礎から理解するための補足資料である。

できるだけ専門用語をほどきながら、以下の3点を中心に説明する。

- 標的タンパク質である BAFF-R とは何か
- Sjogren diseaseなどの自己免疫疾患とBAFF-Rがどう関係するのか
- 最終的にどのような抗体が欲しいのか

## 1. まず超基礎: 自己免疫疾患とB細胞

## 1.1 自己免疫疾患とは

免疫は本来、細菌、ウイルス、がん化した細胞など「体にとって危険なもの」を見つけて排除する仕組みである。

しかし自己免疫疾患では、この免疫システムが自分自身の組織やタンパク質を攻撃してしまう。つまり、敵ではないものを敵と誤認してしまう。

自己免疫疾患で問題になる代表的な要素は以下である。

| 要素 | ざっくり説明 |
|---|---|
| T細胞 | 免疫反応の司令塔・攻撃役。B細胞を助けることもある。 |
| B細胞 | 抗体を作る細胞の元になる。自己抗体の原因にもなる。 |
| 自己抗体 | 自分の体の成分に反応してしまう抗体。 |
| 炎症性サイトカイン | 免疫細胞同士の連絡物質。過剰だと炎症が続く。 |
| 組織障害 | 唾液腺、腎臓、皮膚、関節などが攻撃される。 |

## 1.2 B細胞とは

B細胞は白血球の一種で、抗体産生に関わる細胞である。

B細胞は大まかに以下のように成熟していく。

```text
未熟B細胞
  ↓
成熟B細胞
  ↓
活性化B細胞
  ↓
形質芽細胞
  ↓
形質細胞
  ↓
抗体を大量に作る
```

通常は、病原体に反応する抗体を作るので有益である。

しかし自己免疫疾患では、B細胞が自分自身に反応する抗体、つまり自己抗体を作る方向に進んでしまうことがある。

## 1.3 B細胞が自己免疫で問題になる理由

B細胞は単に抗体を作るだけではない。自己免疫疾患では、以下のように複数の悪さをする可能性がある。

| B細胞の働き | 自己免疫での問題 |
|---|---|
| 抗体を作る | 自己抗体が作られ、組織障害につながる。 |
| 抗原提示をする | T細胞に「攻撃すべき」と情報を渡し、炎症を維持する。 |
| サイトカインを出す | 炎症環境を強める。 |
| 組織に集まる | 唾液腺などで局所炎症を維持する可能性がある。 |

つまり、B細胞は自己免疫疾患でかなり中心的な登場人物になりうる。

## 2. BAFFとは何か

## 2.1 BAFFの基本

BAFFは `B-cell activating factor` の略である。別名として `BLyS`、遺伝子名として `TNFSF13B` とも呼ばれる。

BAFFはB細胞を生かすための生存シグナルである。

かなり単純化すると、BAFFはB細胞に対して次のようなメッセージを送る。

```text
「生き残ってよい」
「成熟してよい」
「抗体産生につながる方向へ進んでよい」
```

このシグナルは正常な免疫には必要である。しかし、自己反応性B細胞にも生存シグナルを与えてしまうと、自己免疫の維持に関わる可能性がある。

## 2.2 BAFFが多すぎると何が問題か

BAFFが多い環境では、本来なら除去されるべき自己反応性B細胞も生き残りやすくなる可能性がある。

イメージとしては、B細胞の選別が甘くなる。

```text
通常:
危険な自己反応性B細胞 → 生き残りにくい

BAFFが多い状態:
危険な自己反応性B細胞 → 生き残りやすくなる可能性
```

このため、BAFF軸はSLEやSjogren diseaseなどのB細胞関連自己免疫疾患で注目されてきた。

## 3. BAFF-Rとは何か

## 3.1 BAFF-Rの名前

今回の標的はBAFFそのものではなく、BAFFを受け取る受容体である。

| 項目 | 内容 |
|---|---|
| 一般名 | BAFF receptor |
| 略称 | BAFF-R |
| 遺伝子名 | TNFRSF13C |
| UniProt ID | Q96RJ3 |
| タンパク質の種類 | B細胞表面の膜タンパク質 |
| 主な役割 | BAFFを受け取り、B細胞の生存を支える |

## 3.2 BAFF-Rはどこにあるのか

BAFF-Rは主にB細胞の表面に発現する。

特に、成熟B細胞で重要な受容体である。

非常にざっくり言うと、以下のようなイメージである。

```text
B細胞の表面
┌─────────────────┐
│                 │
│   BAFF-R        │ ← BAFFが結合する受け皿
│                 │
└─────────────────┘
```

BAFF-Rは細胞の外側に出ている部分を持つため、抗体がアクセスしやすい。これは抗体医薬の標的として重要な特徴である。

## 3.3 BAFF-Rの機能

BAFF-Rの主な機能は、BAFFからのシグナルをB細胞へ伝えること。

BAFFがBAFF-Rに結合すると、B細胞内で生存に関わるシグナルが入る。

```text
BAFF
  ↓ 結合
BAFF-R
  ↓ シグナル伝達
B細胞が生存しやすくなる
```

これにより、成熟B細胞が維持される。

正常免疫では必要な仕組みだが、自己免疫疾患では自己反応性B細胞を生かしてしまう方向に働く可能性がある。

## 4. BAFF-Rを狙う意味

## 4.1 BAFFを狙う方法とBAFF-Rを狙う方法

BAFF軸を止める方法は大きく2つある。

| アプローチ | 何を狙うか | 例 |
|---|---|---|
| BAFF ligand阻害 | BAFFそのものを中和する | belimumabなど |
| BAFF-R阻害 | BAFFを受け取る受容体を止める | ianalumab型の考え方 |

BAFF ligandを中和する場合は、血液や組織中にあるBAFFを捕まえる。

BAFF-Rを狙う場合は、B細胞表面にある受け皿そのものを狙う。

## 4.2 BAFF-Rを狙う利点

BAFF-Rを狙う利点は、B細胞表面の受容体に直接作用できる点である。

期待できる差別化仮説は以下。

| 観点 | BAFF-Rを狙う意味 |
|---|---|
| 選択性 | BAFF-R陽性B細胞に直接作用できる。 |
| 作用の調整 | Fc-silentにすれば阻害中心、Fc-enabledにすれば一部除去も狙える。 |
| 差別化 | BAFF ligand阻害とは異なる薬効プロファイルを作れる可能性。 |
| バイオマーカー | B細胞サブセット、BAFF、IgG、自己抗体などで評価しやすい。 |

## 4.3 ただしBAFF-Rは万能ではない

BAFF-Rを止めても、すべての自己免疫B細胞が消えるわけではない。

特に問題になるのは、以下のような冗長性である。

| 冗長な仕組み | 何が問題か |
|---|---|
| APRIL | BAFFとは別にB細胞/形質細胞を支える可能性がある。 |
| CD40L-CD40 | T細胞からB細胞への助けが残る。 |
| IL-21 | B細胞分化を支えるT細胞由来サイトカイン。 |
| 組織内ニッチ | 唾液腺など局所でB細胞が生き残る可能性。 |
| 長寿命形質細胞 | BAFF-Rをあまり使わずに抗体を作り続ける可能性。 |

したがって、BAFF-R抗体は「B細胞性自己免疫なら何でも効く薬」ではない。

効きそうな患者を選ぶことが重要になる。

## 5. 疾患との関係: なぜSjogren diseaseなのか

## 5.1 Sjogren diseaseとは

Sjogren diseaseは、主に涙腺や唾液腺が障害される自己免疫疾患である。

典型的には以下のような症状がある。

| 症状・問題 | 内容 |
|---|---|
| 口腔乾燥 | 口が乾く、虫歯が増える、飲み込みにくい。 |
| 眼乾燥 | 目が乾く、痛い、異物感がある。 |
| 疲労 | 強い倦怠感が続くことがある。 |
| 疼痛 | 関節痛や筋肉痛など。 |
| 全身病変 | 肺、腎、神経、血管などが関わる場合がある。 |
| リンパ腫リスク | 一部患者でB細胞リンパ腫リスクが上がる。 |

## 5.2 Sjogren diseaseでB細胞が重要な理由

Sjogren diseaseでは、B細胞の異常がしばしば観察される。

代表的には以下。

| 所見 | 意味 |
|---|---|
| 抗SSA/Ro抗体 | 自己抗体。診断や病態理解に関わる。 |
| 抗SSB/La抗体 | 自己抗体。 |
| 高IgG血症 | 抗体産生が高まっている状態を示す。 |
| RF陽性 | B細胞活性化の一部を反映することがある。 |
| 低補体 | 免疫複合体や全身活動性と関係することがある。 |
| 唾液腺へのリンパ球浸潤 | 局所で免疫反応が続いている可能性。 |

これらは、Sjogren diseaseの少なくとも一部がB細胞性自己免疫疾患として理解できることを示す。

## 5.3 BAFF-RとSjogren diseaseの関係

事実として、BAFF/BAFF-R軸はB細胞の生存に関わる。

推論として、Sjogren diseaseでB細胞が過剰に活性化している患者では、BAFF-Rを止めることで自己反応性B細胞の維持を弱められる可能性がある。

特に狙いたい患者像は以下。

| 患者像 | 理由 |
|---|---|
| 自己抗体陽性 | B細胞/抗体病態が関わっている可能性。 |
| 高IgG | B細胞・形質細胞系が活発な可能性。 |
| plasmablast高値 | 抗体産生へ向かうB細胞が活発な可能性。 |
| BAFF高値 | BAFF依存性が高い可能性。 |
| 全身活動性がある | 乾燥症状のみより薬効を検出しやすい可能性。 |
| 唾液腺B細胞浸潤が強い | 局所B細胞病態を狙える可能性。 |

## 5.4 乾燥症状だけを狙う難しさ

Sjogren diseaseで注意すべき点は、乾燥症状が必ずしもすぐ改善するとは限らないこと。

もし唾液腺や涙腺が長期間の炎症で構造的に壊れている場合、B細胞を抑えても機能がすぐ戻らない可能性がある。

そのため、開発上は以下のどちらを狙うかを慎重に考える必要がある。

| 狙うもの | 利点 | 難しさ |
|---|---|---|
| 乾燥症状改善 | 患者にとって分かりやすい | 腺組織が壊れていると戻りにくい可能性 |
| 全身活動性改善 | 免疫抑制の効果が見えやすい可能性 | 患者選択が必要 |
| バイオマーカー改善 | 早期にPDを見やすい | 臨床症状との対応が必要 |

このシーズでは、最初から「乾燥症状だけ」を主戦場にするより、B-cell-highで全身活動性や明確なバイオマーカーを持つ患者を想定する方がよい。

## 6. 既存薬・競合との関係

## 6.1 BAFF ligand阻害: belimumab

BelimumabはBAFFを阻害する抗体医薬で、SLEやlupus nephritisで承認されている。

これはBAFF軸がヒト自己免疫疾患で治療標的になりうることを示している。

一方で、belimumabはすべての患者に強く効く薬ではない。効果は患者により異なり、既存治療との併用や時間を要することもある。

つまり、BAFF軸は妥当だが、より良い患者選択や作用様式の差別化が必要である。

## 6.2 BAFF-R抗体: ianalumab

IanalumabはBAFF-Rを標的とする抗体として臨床開発されている。

これは、BAFF-Rが抗体で狙える標的であることを示す重要な先行例である。

一方で、競合が存在するという意味でもある。

したがって、新規シーズとしては単に「BAFF-Rを狙う」だけでは弱い。

必要なのは以下のような差別化である。

| 差別化軸 | 内容 |
|---|---|
| Fc設計 | Fc-silentで慢性安全性を重視する、または限定的depletionを狙う。 |
| 患者選択 | B-cell-high / BAFF-high / 自己抗体陽性などに絞る。 |
| 疾患選択 | Sjogrenの中でも全身活動性やB細胞病態が強い患者を狙う。 |
| PD設計 | B細胞サブセット、IgG、自己抗体、補体などを早期に追う。 |
| 投与設計 | 慢性疾患で無理のない投与間隔・安全性を狙う。 |

## 6.3 失敗例から学ぶこと

BAFF軸では、過去に失敗や懸念もある。

| 例 | 何が問題だったか | 今回への教訓 |
|---|---|---|
| Tabalumab | BAFF阻害で臨床有効性が十分でなかった。 | BAFF軸だから効く、とは言えない。 |
| Atacicept | BAFF/APRILを広く抑える設計で、疾患によっては悪化懸念があった。 | B細胞軸の抑制は強ければよいわけではない。 |
| Belimumabの限界 | 効果が患者により異なり、全員に強く効くわけではない。 | 患者選択と薬効readoutが重要。 |
| Ianalumab競合 | BAFF-R直接標的の先行開発がある。 | 新規性は設計・患者選択・適応で出す必要がある。 |

## 7. 競合はBAFF-R依存患者を選んでいるのか

ここはとても重要である。

もし競合品がすでに「BAFF-R依存的にB細胞活性が維持されている患者」だけを選んで開発しているなら、この提案の差別化は弱くなる。

現時点の公開情報ベースでは、結論は以下である。

```text
BAFF-Rを標的にした薬はある。
しかし、BAFF-R依存性そのものを機能的に確認して患者選択している競合は、少なくとも明確には見当たらない。
```

## 7.1 ianalumabはかなり近いが、同じではない

IanalumabはBAFF-Rを標的とする抗体である。

そのため、競合としては最も近い。

ただし、公開されているSjogren disease試験の主な患者選択は、BAFF-R依存性ではなく、以下のような臨床・診断条件である。

| 条件 | 意味 |
|---|---|
| active Sjogren disease | 活動性がある患者 |
| anti-Ro/SSA陽性 | Sjogrenらしい自己抗体を持つ患者 |
| anti-Ro/SSA陰性なら唾液腺生検陽性 | 診断確度を担保する条件 |
| ESSDAI一定以上 | 全身活動性がある患者 |
| stimulated salivary flow一定以上 | 唾液腺機能が完全に失われていない患者 |

これは合理的な患者選択である。

しかし、次のような問いには直接答えていない。

```text
その患者のB細胞は、本当にBAFF-Rシグナルに依存して生き残っているのか？
抗BAFF-R抗体で、その患者B細胞の活性はex vivoで落ちるのか？
BAFF ligand阻害よりBAFF-R直接阻害の方が、その患者では強いのか？
```

この違いが、こちらの提案の差別化ポイントになる。

## 7.2 競合品・関連薬剤との違い

| 薬剤/試験 | 標的 | どんな患者を選んでいるか | BAFF-R依存患者を選んでいるか |
|---|---|---|---|
| ianalumab / VAY736 | BAFF-R | active Sjogren、anti-Ro/SSA陽性、ESSDAI、唾液分泌など | いいえ。BAFF-R標的薬だが、BAFF-R依存性では選んでいない |
| ianalumab biopsy MoA study | BAFF-R | anti-Ro/SSA陽性、ESSPRI高値など | いいえ。機序理解に近いが、BAFF-R依存性選択ではない |
| sibeprenlimab | APRIL | Sjogren、IgG高値、anti-Ro52/60陽性など | 近いが違う。B-cell/抗体high寄りだがBAFF-R依存ではない |
| belimumab | BAFF | autoantibody-positive SLE、anti-dsDNA/低補体など | BAFF軸だがBAFF-R依存ではない |
| atacicept | BAFF/APRIL | active SLE、ANA/anti-dsDNA陽性など | BAFF/APRIL軸だがBAFF-R依存ではない |
| tabalumab | BAFF | active SLE、ANA陽性など | BAFF阻害だがBAFF-R依存ではない |

## 7.3 つまり何が差別化になるのか

単にBAFF-Rを狙うだけでは、ianalumabと近すぎる。

差別化するには、患者選択を一段深くする必要がある。

狙いたいのは、以下のような患者である。

```text
BAFF-R陽性B細胞が多いだけでなく、
BAFF刺激でそのB細胞が実際に生存・活性化し、
抗BAFF-R抗体でその反応が明確に抑えられる患者。
```

このような患者を、ここでは便宜的に `BAFF-R依存患者` と呼ぶ。

## 8. ianalumabで解決できていない可能性がある課題

## 8.1 まず正直な前提

Ianalumabはかなり強い競合である。

BAFF-Rを標的にしており、Sjogren diseaseで大規模なPhase 3試験が進んでいる。公開試験情報では、主要評価項目はWeek 48のESSDAI変化であり、二次評価項目にはSSSD、ESSPRI、FACIT-F、stimulated salivary flowなどが含まれる。

つまりianalumabは、全身活動性だけでなく、症状、疲労、唾液分泌のような患者価値に近い項目も見に行っている。

したがって、こちらの提案は以下のように考える必要がある。

```text
ianalumabと同じことをやるだけなら勝てない。
ianalumabで残る可能性がある課題を、より鋭く解く必要がある。
```

## 8.2 ianalumabで残りうる課題

公開情報から考えると、ianalumabで未解決になりうる課題は以下である。

| 課題 | なぜ残りうるか | こちらの打ち手 |
|---|---|---|
| どの患者が本当に効くか | anti-Ro/SSA、ESSDAI、唾液分泌などで選んでいるが、BAFF-R依存性そのものではない | BAFF-R dependency scoreとex vivo機能アッセイで患者を濃縮する |
| 乾燥症状がどこまで改善するか | 腺が壊れている患者では、免疫を抑えても機能回復しにくい可能性 | 残存唾液分泌、唾液腺B細胞浸潤、局所BAFF/BAFF-R発現で可逆性のある患者を選ぶ |
| 疲労・疼痛がどこまで改善するか | 疲労や疼痛はB細胞だけでなく神経、サイトカイン、心理社会的要因も関わる | B-cell-highかつ全身活動性/炎症性readoutがある患者に絞る |
| 慢性安全性 | BAFF-R標的でB細胞抑制/除去が起こると感染、低IgG、ワクチン応答低下が問題になる | Fc-silent blockingで、過剰なB細胞depletionを避ける |
| 後発品との差別化 | BAFF-Rを直接狙う点は同じ | 非depleting寄り、機能的患者選択、腺局所バイオマーカーで差別化する |

## 8.3 一番大きな差別化余地

一番大きな差別化余地は、抗体そのものよりも患者選択にある。

IanalumabはBAFF-Rを標的にしているが、公開情報ベースでは「この患者のB細胞はBAFF-Rに依存している」と機能的に確認して選んでいるわけではない。

こちらが狙うべきなのは、次のような患者である。

```text
BAFF-Rが発現している
  +
BAFF刺激でB細胞が生き残る/活性化する
  +
抗BAFF-R抗体でその反応が止まる
  +
その反応が疾患readoutとつながる
```

この4つが揃えば、単なるanti-BAFF-Rではなく、`BAFF-R依存B細胞病態を狙う精密治療` として説明できる。

## 8.4 もう一つの差別化余地: depletingではなくmodulating

BAFF-R抗体には、B細胞を枯渇させる方向の設計と、BAFF-Rシグナルをブロックする方向の設計がある。

慢性自己免疫疾患では、強いB細胞枯渇は効く可能性がある一方で、安全性上の課題も大きい。

| 設計思想 | 期待 | 懸念 |
|---|---|---|
| Depleting BAFF-R antibody | 強いB細胞制御 | 感染、低IgG、ワクチン応答低下 |
| Fc-silent blocking antibody | 生存シグナルを抑えるが細胞傷害は抑える | 薬効が弱い可能性 |
| Moderate Fc-enabled antibody | 必要な患者だけ限定的に除去 | 安全性と薬効のバランス設計が難しい |

もしianalumabがdepleting寄りの強いB細胞制御で差を出す薬だとすれば、こちらは `非depleting寄りで安全に長く使えるBAFF-R modulator` を狙う余地がある。

ただし、これは仮説である。Fc-silent化して薬効が弱くなれば意味がない。

## 9. ファーストインクラスになるには何が必要か

## 9.1 BAFF-R抗体としてのファーストインクラスは難しい

ここは厳密に考える必要がある。

IanalumabがBAFF-R抗体として承認されれば、その後に出すBAFF-R抗体は、標的ベースではファーストインクラスではない。

つまり、以下の主張は弱い。

```text
BAFF-Rを標的にする新規抗体です。
```

なぜなら、BAFF-R標的の先行薬がすでに存在するからである。

## 9.2 ファーストインクラスと言える可能性がある形

それでも、治療コンセプトとして新しければ、別の意味でファーストインクラスを狙える可能性はある。

例えば以下である。

| 方向性 | ファーストインクラスと言える可能性 |
|---|---|
| First biomarker-defined BAFF-R therapy | BAFF-R dependency scoreで患者を選ぶ初のBAFF-R治療 |
| First non-depleting BAFF-R modulator | B細胞枯渇ではなくBAFF-R survival signalのみを主に抑える治療 |
| First salivary-gland-preserving BAFF-R strategy | 腺機能が残る患者を選び、腺機能維持/回復を狙う治療 |
| First functional ex vivo-selected Sjogren biologic | 患者B細胞のex vivo反応性で治療選択するSjogren biologic |

ただし、これはマーケティング上の言い方だけでは足りない。

実験と臨床設計で本当に違いを示す必要がある。

## 9.3 必要な薬剤プロファイル

ファーストインクラスに近い主張をするには、以下のプロファイルが必要である。

| 項目 | 必要なプロファイル |
|---|---|
| 患者選択 | BAFF-R dependency scoreまたはex vivo assayで反応患者を事前に選べる |
| MoA | BAFF-R発現細胞を広く枯渇させるのではなく、BAFF-R依存 survival signalを選択的に遮断する |
| 安全性 | 低IgG、感染、ワクチン応答低下がdepleting型より軽い |
| 臨床価値 | ESSDAIだけでなく、乾燥、疲労、唾液分泌、ステロイド削減など患者価値に近いreadoutを改善する |
| 差別化 | BAFF ligand阻害、BAFF/APRIL阻害、CD20/CD19枯渇、ianalumab型BAFF-R抗体と比較して、PD/安全性/患者選択が違う |
| Developability | 慢性投与できるIgG物性、低免疫原性、皮下注射可能性を持つ |

## 9.4 現実的な言い方

現時点では、正直に言うと、`ファーストインクラスBAFF-R抗体` というより、

```text
BAFF-R依存患者を機能的に選ぶ、precision BAFF-R modulator
```

または、

```text
first biomarker-defined BAFF-R therapy
```

を狙う方が現実的である。

より事業的な表現では、`best-in-class / precision-in-class` に近い。

## 9.5 この方向で勝てる条件

この方向で勝つには、以下のどれか一つでは足りない。

複数を同時に満たす必要がある。

| 条件 | なぜ必要か |
|---|---|
| BAFF-R依存患者を同定できる | 競合との差別化の中核 |
| Fc-silentでも十分に効く | 安全性差別化の前提 |
| ianalumab型depletionより安全側 | 後発でも使う理由になる |
| BAFF ligand阻害よりPDが強い | BAFF-R直接標的の意味を示す |
| 症状/腺機能に効く患者を選べる | 患者価値に近い差別化になる |
| 実験系が簡便 | 将来の患者選択・臨床開発に使える |

逆に、これらが示せない場合は、このシーズはianalumab後追いになりやすい。

## 10. BAFF-R依存患者をどう見つけるか

## 10.1 単一マーカーでは足りない

BAFF-R依存性を一発で判定できる単一バイオマーカーは、現時点では不明である。

例えば、serum BAFFが高い患者はBAFF軸が強そうに見える。

しかし、serum BAFFが高いだけでは以下が分からない。

- B細胞がBAFF-Rを十分に発現しているか
- そのB細胞がBAFFに反応するか
- 抗BAFF-R抗体で本当に反応が止まるか
- APRILやCD40Lなど別経路でrescueされないか

したがって、血液マーカー、組織マーカー、機能アッセイを組み合わせる必要がある。

## 10.2 血液で見たいマーカー

| Biomarker | 何を見ているか | 注意点 |
|---|---|---|
| Serum BAFF高値 | BAFF環境が強い可能性 | BAFF-R依存とは限らない |
| BAFF-R陽性B細胞割合 | 標的細胞がどれくらいいるか | 発現だけでは機能依存性は不明 |
| BAFF-R MFI | B細胞1個あたりのBAFF-R量 | flow cytometryで測る |
| Plasmablast高値 | 抗体産生へ向かうB細胞が多い | APRIL/BCMA依存の可能性もある |
| IgG高値 | 抗体産生系が強い | 非特異的 |
| RF陽性 | B細胞自己免疫の指標 | Sjogrenでは有用だがBAFF-R直接ではない |
| anti-SSA/Ro陽性 | Sjogrenらしい自己抗体 | 競合試験でも使われるので差別化には弱い |
| 低C3/C4 | 免疫複合体・全身活動性の指標 | 重症度マーカー寄り |
| Free light chain高値 | B細胞/形質細胞活性 | BAFF-R依存とは限らない |

## 10.3 組織で見たいマーカー

Sjogren diseaseでは、唾液腺組織が重要である。

血液では目立たなくても、唾液腺局所でB細胞反応が起きている可能性がある。

| Tissue marker | 意味 |
|---|---|
| 唾液腺B細胞浸潤 | 局所B細胞病態が強い |
| BAFF / TNFSF13B発現 | 局所BAFF環境がある |
| BAFF-R+ B細胞 | 標的細胞が局所にいる |
| CXCL13 | B細胞を呼び寄せるケモカイン |
| CXCR5+ B/T cells | リンパ濾胞様反応の可能性 |
| Ectopic germinal center-like structure | 局所でB細胞反応が維持されている可能性 |
| IFN signature | IFNがBAFF産生を誘導している可能性 |

## 10.4 一番重要なのは機能アッセイ

最も重要なのは、患者由来B細胞を使った機能アッセイである。

これは「マーカーが高いから効きそう」ではなく、「実際にその患者のB細胞がBAFF-Rに依存しているか」を見る方法である。

イメージは以下。

```text
患者B細胞を取り出す
  ↓
BAFFを加える
  ↓
B細胞が生存・活性化するか見る
  ↓
抗BAFF-R抗体を加える
  ↓
その反応が落ちるか見る
```

見たいreadoutは以下である。

| Readout | 意味 |
|---|---|
| B細胞生存率 | BAFF-Rが生存に効いているか |
| CD69 / CD86 | B細胞活性化が落ちるか |
| NF-kB pathway | BAFF-R下流シグナルが止まるか |
| BCL2 / MCL1 | 生存シグナルが下がるか |
| Plasmablast分化 | 抗体産生方向への分化が抑えられるか |
| Ig産生 | 抗体産生が下がるか |
| 自己抗体関連readout | 疾患に近い抗体反応が下がるか |

## 10.5 BAFF-R dependency scoreの案

実用上は、複数のマーカーを組み合わせて `BAFF-R dependency score` のようなものを作るのがよい。

| Category | Marker / assay | 重みづけイメージ |
|---|---|---|
| Ligand | serum BAFF、唾液腺BAFF/TNFSF13B | Medium |
| Receptor | BAFF-R MFI、BAFF-R+ B細胞割合 | Medium |
| B-cell activation | plasmablast、CD21low B cells、activated naive B cells | Medium |
| Humoral activity | IgG、RF、anti-SSA/Ro、free light chains | Low-Medium |
| Systemic activity | ESSDAI、低補体、cryoglobulin | Low-Medium |
| Tissue biology | 唾液腺B細胞浸潤、CXCL13、ectopic GC-like structure | Medium-High |
| Functional dependency | BAFF刺激反応が抗BAFF-R抗体で抑制される | High |

この中で最も重要なのはfunctional dependencyである。

serum BAFF高値、anti-SSA陽性、IgG高値は役に立つが、それだけではBAFF-R依存性の証明にはならない。

## 10.6 このバイオマーカー戦略の意味

この提案の本当の差別化は、抗体そのものだけではない。

むしろ、以下の組み合わせである。

```text
BAFF-R blocking antibody
  +
BAFF-R dependencyで患者を濃縮する診断・評価戦略
```

これができれば、既存の `active Sjogren / anti-Ro陽性 / ESSDAI高値` という選び方よりも、薬が効きやすい患者を狙える可能性がある。

## 11. どのような抗体が欲しいのか

## 11.1 一番欲しい抗体像

最も欲しいのは、以下のような抗体である。

```text
B-cell-high Sjogren disease患者において、
BAFF-Rを強く、選択的にブロックし、
過剰なB細胞活性を下げるが、
広範で長期の免疫不全は起こしにくい抗体。
```

もう少し技術的に書くと、主案は以下である。

| 項目 | 欲しい特徴 |
|---|---|
| 標的 | BAFF-R / TNFRSF13C |
| 結合部位 | BAFF結合を阻害できる細胞外ドメイン |
| 主作用 | BAFF-R blocking |
| Fc機能 | まずはFc-silentを主案 |
| 細胞傷害 | 基本は起こさない。必要なら限定的に検討。 |
| 投与 | 慢性自己免疫疾患で許容できる間隔 |
| 安全性 | 低IgG、感染、ワクチン応答低下を最小化 |
| 患者選択 | B-cell-high、BAFF-high、自己抗体陽性など |

## 11.2 なぜblocking antibodyなのか

BAFF-RはBAFFを受け取ることでB細胞に生存シグナルを送る。

したがって、BAFFがBAFF-Rに結合できないようにすれば、BAFF依存性のB細胞生存を弱められる可能性がある。

```text
通常:
BAFF → BAFF-R → B細胞生存

blocking antibodyあり:
BAFF ✕ BAFF-R → 生存シグナル低下
```

これがblocking antibodyの基本的な狙いである。

## 11.3 なぜFc-silentが主案なのか

抗体には、標的に結合する部分と、免疫細胞に作用を伝えるFc部分がある。

Fcが強く働くと、標的細胞を殺すADCC/CDCなどが起こる可能性がある。

B細胞を殺すこと自体は、自己免疫では薬効につながる可能性がある。しかし、慢性疾患ではやりすぎると以下が問題になる。

| 問題 | 説明 |
|---|---|
| 感染 | B細胞や抗体が減りすぎると感染に弱くなる。 |
| 低IgG | 体を守る抗体が減る。 |
| ワクチン応答低下 | ワクチンを打っても十分な免疫がつかない可能性。 |
| 長期安全性 | Sjogrenは慢性疾患なので、長く使える安全域が必要。 |

そのため、最初はFc-silent、つまりFcによる細胞傷害を抑えた抗体を主案にする。

## 11.4 Fc-enabled案は完全に捨てるべきか

捨てる必要はない。

高活動性でB細胞病態が非常に強い患者では、単にBAFF-Rをブロックするだけでは不十分かもしれない。

その場合、少しだけB細胞を除去するFc-enabled設計が有効な可能性がある。

ただし、これは副案である。

| 設計 | 位置づけ |
|---|---|
| Fc-silent blocking | 主案。安全性重視。 |
| Moderate Fc-enabled blocking/depleting | 副案。高活動性患者向け。 |
| Strong Fc-enhanced depleting | 慎重。CD20/CD19枯渇との差別化が難しい。 |
| ADC | 非推奨。自己免疫には毒性が強すぎる。 |
| Agonistic antibody | 非推奨。B細胞を活性化してしまう恐れ。 |

## 11.5 欲しい抗体の具体的な性質

## Binding

- BAFF-Rに高い特異性で結合する。
- BAFFの結合をしっかり阻害する。
- TACIやBCMAなど近縁分子には不要に結合しない。
- B細胞上のBAFF-Rに結合できる。

## Function

- BAFF依存性B細胞生存を抑える。
- 自己免疫患者由来B細胞で、B-cell activation signatureを下げる。
- 可能ならplasmablastや自己抗体産生方向への分化を抑える。
- Fc-silent案ではADCC/CDCをほぼ起こさない。

## Safety

- 正常B細胞を過剰に減らしすぎない。
- IgGを下げすぎない。
- 強いサイトカイン放出を起こさない。
- 慢性投与で免疫不全になりにくい。

## Developability

- 通常IgGとして製造しやすい。
- 凝集しにくい。
- 粘度が高くなりすぎない。
- 免疫原性リスクが低い。
- 必要なら皮下注射に向く物性を持つ。

## 12. 最初に確認すべき実験

## 12.1 標的にちゃんと結合するか

まず、抗体がBAFF-Rに結合する必要がある。

確認したいこと。

| 実験 | 見たいこと |
|---|---|
| recombinant BAFF-R binding | タンパク質レベルで結合するか。 |
| B細胞flow cytometry | 細胞表面BAFF-Rに結合するか。 |
| specificity assay | TACI/BCMAなどに不要に結合しないか。 |
| competition assay | BAFFと競合してBAFF-Rをふさぐか。 |

## 12.2 BAFF依存性B細胞生存を抑えるか

次に、機能を確認する。

BAFFを加えるとB細胞が生き残りやすくなる系を作り、抗BAFF-R抗体でそれが抑えられるかを見る。

| 実験 | 見たいこと |
|---|---|
| BAFF-induced B-cell survival assay | BAFFによるB細胞生存が抑えられるか。 |
| NF-kB pathway readout | BAFF-R下流シグナルが下がるか。 |
| B-cell activation marker | CD69, CD86などが下がるか。 |

## 12.3 患者サンプルで効くか

健康人B細胞で効いても、疾患で意味があるとは限らない。

そのため、Sjogren disease患者由来サンプルで確認する必要がある。

| サンプル | 見たいこと |
|---|---|
| 患者PBMC | B細胞活性化が下がるか。 |
| 自己抗体陽性患者サンプル | 自己抗体産生方向のreadoutが下がるか。 |
| 高IgG患者サンプル | Ig産生関連readoutが動くか。 |
| 唾液腺組織 ex vivo | 局所B細胞/炎症readoutが下がるか。 |

## 12.4 既存薬との差を見せる

社内提案として重要なのは、「効きそう」だけでなく「既存薬と何が違うのか」である。

比較対象としては以下。

| 比較対象 | 見る意味 |
|---|---|
| BAFF ligand阻害 | BAFF-R直接標的の優位性を見る。 |
| CD20/CD19枯渇 | B細胞除去薬との違いを見る。 |
| BAFF/APRIL dual blockade | 強いB細胞軸阻害との違いを見る。 |

## 12.5 安全性の初期確認

初期から見るべき安全性readout。

| リスク | 初期評価 |
|---|---|
| 過剰B細胞減少 | B細胞サブセット別の生存率を見る。 |
| 低IgGリスク | Ig産生readout、plasmablastへの影響を見る。 |
| ADCC/CDC | Fc-silent案では陰性確認する。 |
| cytokine release | PBMCで炎症性サイトカインを確認する。 |
| off-target binding | protein arrayや細胞パネルで確認する。 |

## 13. Go / No-Goをどう考えるか

## 13.1 Goにしたい結果

以下が揃うと前に進めやすい。

| 項目 | Goのイメージ |
|---|---|
| 標的発現 | B-cell-high Sjogren患者でBAFF-R陽性B細胞が明確。 |
| 機能依存性 | BAFF-R blockadeでB細胞生存/活性化readoutが下がる。 |
| 患者選択 | BAFF-high、高IgG、自己抗体陽性などで反応が強い。 |
| 機能的患者選択 | BAFF-R dependency scoreまたはex vivo assayで反応患者を濃縮できる。 |
| ianalumabとの差別化 | Fc-silent/患者選択/症状・腺機能readoutのどれかで明確に上回る仮説がある。 |
| 差別化 | BAFF ligand阻害より良いPD、またはCD20枯渇より安全側。 |
| 安全性 | Fc-silentでADCC/CDC陰性、過剰Ig低下が少ない。 |

## 13.2 No-Goにすべき結果

以下なら止めるべき。

| 項目 | No-Goの理由 |
|---|---|
| BAFF-R発現が弱い | 標的が足りない。 |
| BAFF-Rを止めてもB細胞readoutが動かない | 標的が病態ドライバーではない可能性。 |
| BAFF ligand阻害と同じ | 新規性・差別化が弱い。 |
| ianalumabと同じ | 後追いBAFF-R抗体になり、ファーストインクラス性がない。 |
| CD20/CD19枯渇に劣る | B細胞標的として勝ち筋が薄い。 |
| 相関マーカーしかない | BAFF-R依存性を機能的に示せない。 |
| IgGが下がりすぎる | 慢性自己免疫薬として安全性が厳しい。 |
| 感染リスクreadoutが強い | 長期投与が難しい。 |

## 14. この提案のいちばん大事な仮説

この提案の核は、以下である。

```text
Sjogren diseaseの中には、
BAFF-R依存的にB細胞活性が維持されている患者サブセットがあり、
そこではBAFF-Rを選択的にブロックする抗体が、
BAFF ligand阻害や広範B細胞枯渇とは異なる価値を出せる。
```

これはまだ仮説である。

したがって、最初の検証では「BAFF-R抗体を作れるか」よりも先に、「本当にBAFF-R依存の患者サブセットがあるか」を確認することが重要である。

## 15. 一言でまとめると

BAFF-R抗体は、B細胞が強く関わるSjogren diseaseサブセットを狙う抗体シーズとして合理性がある。

ただし、BAFF軸は過去に成功も失敗もあり、競合も存在するため、「BAFF-Rを狙う」だけでは提案として弱い。

勝ち筋は、B-cell-high患者を選ぶだけでなく、BAFF-R依存性を機能的に確認し、Fc-silent blocking antibodyで慢性安全性を確保し、ianalumab、BAFF ligand阻害、CD20/CD19枯渇とは違うPD/安全性/患者選択プロファイルを示すことである。
