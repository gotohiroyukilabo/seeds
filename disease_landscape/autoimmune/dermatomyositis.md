# Dermatomyositis

調査日: 2026-07-05

## 評価サマリー

| 観点 | 初期評価 |
|---|---|
| Unmet medical need | Medium-High |
| 抗体で介入しやすい病態か | Medium-High |
| 細胞外・膜タンパク質標的 | IFNAR1, BDCA2, FcRn, complement C5/C5a, B-cell targets |
| バイオマーカー患者選択 | Medium-High |
| 競合過密度 | Low-Medium |

## 事実

- 皮膚、筋炎、間質性肺疾患、悪性腫瘍関連など多様なフェノタイプを持つ自己免疫疾患。
- Type I IFN signature、筋炎特異的自己抗体、補体、B細胞/形質細胞、皮膚病変が病態に関与する。
- 自己抗体サブタイプにより臨床像と予後が異なる。
- FcRn、IFN pathway、補体など抗体標的化可能な軸がある。

## 推論 / 仮説

- IFN-high皮膚優位、自己抗体陽性、難治性ILDなどに分けると、抗体介入のシーズ探索価値が高まる。
- 疾患異質性が大きいため、広いDM全体を対象にするとシグナルが希釈される可能性がある。

## 標的候補

| 標的候補 | 抗体介入の考え方 | 根拠の方向性 | 懸念 |
|---|---|---|---|
| IFNAR1 / pDC targets | type I IFN経路抑制 | IFN signature | 感染リスク、SLE競合 |
| FcRn | 病原性IgG自己抗体低下 | 自己抗体サブタイプ | DMでの有効性は不明 |
| C5 / C5a | 補体介在組織障害抑制 | 補体沈着・筋/皮膚病理 | 感染、患者選択 |
| CD19/CD20 | B細胞軸制御 | 自己抗体疾患 | 効果予測と競合 |

## 不明点

- 自己抗体ごとの最適標的は不明。
- 筋、皮膚、ILDのどれを主アウトカムにすべきかは不明。
- 臨床試験の患者数確保と評価指標の感度は不明。
