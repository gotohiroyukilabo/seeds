# 提案1 詳細メモ: IGHV4-34病的BCR選択的engager

作成日: 2026-07-08

## 0. このレポートの目的
`outputs/seed_proposal_1.md` の内容を、自分で説明できるレベルまで噛み砕くためのメモである。

中心の問いは、なぜCD19/CD20ではなく病的BCR frameworkを狙うのか、抗体薬でCAR-Tに近い選択性を作れるのか、どの実験で早く殺せるのかである。

## 1. B細胞とBCRの基礎
B細胞はBCRで抗原を認識し、活性化して形質芽細胞、形質細胞へ進み、抗体を作る。自己免疫では、このBCRが自己抗原を認識してしまう。

```text
B細胞 → BCRで自己抗原認識 → 活性化 → 形質芽細胞 → 形質細胞 → 自己抗体
```

既存B細胞治療は、CD20やCD19のような共通マーカーを狙う。強力だが、正常B細胞も巻き込む。

## 2. IGHV4-34とは何か
IGHV4-34は抗体重鎖可変領域の遺伝子セグメントである。通常の膜タンパク質ではなく、再構成されたBCRの一部としてB細胞表面に現れる。

| 項目 | 内容 |
|---|---|
| 標的 | IGHV4-34陽性BCR framework |
| UniProt ID | 該当なし |
| 場所 | B細胞表面BCR |
| 疾患仮説 | 9G4/IGHV4-34高値SLE/LN |

IGHV4-34由来抗体は自己反応性を持ちやすく、SLEの9G4抗体や自己反応性B細胞と関係する。

## 3. なぜSLE/LNなのか
SLE/LNでは自己抗体、免疫複合体、補体、腎炎が絡む。治療は増えたが、再燃、腎反応不十分、ステロイド毒性、感染が残る。

重要なのは、SLE全員ではなく、IGHV4-34/9G4 biologyが強い患者に絞ることである。

## 4. 2026年CAR-T報告の意味
CART4-34は、CD19ではなくIGHV4-34 BCR frameworkを狙う発想を示した。これは「病的B細胞をB細胞マーカーではなくBCRで見分ける」考え方である。

CAR-Tは強力だが、製造、リンパ球除去、CRS/ICANS、感染、費用が重い。抗体で同じ方向性を作れれば、実装しやすいprecision B-cell resetになる。

## 5. 抗体設計
| 設計 | 位置づけ | 主なリスク |
|---|---|---|
| IGHV4-34 x CD3 BsAb | 強力なT細胞誘導 | CRS/ICANS |
| IGHV4-34 x CD16a BsAb | NK細胞誘導 | ADCCばらつき |
| Fc強化anti-IGHV4-34 | 比較的単純な選択的depletion | 正常IGHV4-34 B細胞喪失 |
| IGHV4-34 ADC | T細胞サイトカインを避ける | payload毒性、internalization依存 |
| masked BsAb | 全身毒性を抑える | mask設計難度 |

CD3を最初から本命に固定せず、CD16a、Fc強化、ADCも並べて安全域を見る。

## 6. 革新性
この提案の革新性は技術名ではない。自己免疫を「全B細胞の病気」ではなく「病的BCRクローンの病気」として扱う点である。

## 7. 既存薬との差
rituximab/CD20、inebilizumab/CD19、belimumab/BAFF、FcRn阻害は広くB細胞またはIgGを動かす。本提案は病的BCRを持つB細胞を選ぶ。

## 8. 患者選択
9G4抗体、IGHV4-34+ B細胞、BCR sequencing、形質芽細胞、抗dsDNA、低補体、尿中CXCL13を組み合わせる。

## 9. 主なリスク
患者割合が少ない、血中Igシンク、CRS、bystander killing、IGHV4-34陰性クローン残存、規制上の標的定義。

## 10. 最初の検証
患者サンプルで、IGHV4-34+ B細胞の頻度、血清存在下binding、選択的killing、cytokine release、自己抗体産生抑制を見る。

## 11. 継続/中止基準
継続条件: severe SLE/LNの15-20%以上に標的biology、10倍以上の選択性、自己抗体低下、低cytokine。

中止条件: serum Ig sinkで失効、bystander killing、標的細胞が疾患活動性と無関係。

## 12. 最終コメント
