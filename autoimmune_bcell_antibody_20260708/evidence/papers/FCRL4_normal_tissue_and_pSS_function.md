# 正常組織とpSS病変組織におけるFcRL4の機能

作成日: 2026-08-26

## エグゼクティブサマリー

1. 正常組織のFcRL4は、血中B細胞に広く発現する分子ではなく、扁桃crypt、腸管リンパ組織、腸間膜リンパ節など、上皮に接する粘膜関連リンパ組織のmemory B cell subsetに偏っている。
2. FcRL4分子について直接示された中心機能は、ITIM/ITIM-like tyrosine、SHP-1/SHP-2を介したBCR-Syk-PLCγ2-Vav-Caシグナルの抑制と、TLR9/CpG応答の増強である。したがって「B細胞を全面的に疲弊させるブレーキ」ではなく、**抗原特異的なadaptive/BCR応答を弱め、innate/TLR応答を相対的に優位にするswitch**と考える方がよい。
3. 正常FcRL4陽性memory B細胞のBCRはcommensal microbial antigenへの反応性に富む。生理的には、抗原と微生物刺激が絶えない粘膜境界で、BCR単独による過剰増殖を防ぎながら、TLR、CD40、T細胞cytokineを含む複数signalがそろった時には抗体産生・局所応答を許すgateである可能性が高い。ただし、外来ウイルス反応を抑えることが主目的だと直接証明した文献はない。
4. FcRL4の生理的ligandは、現在の理解ではJ-chainを含むsystemic dimeric IgAであり、secretory componentを持つmucosal secretory IgAには結合しにくい。2026年の構造研究ではFcRL4は主にJ-chainを認識し、IgAまたはIgA immune complexをinternalizeしないと報告された。したがってFcRL4は典型的な粘膜sIgA回収受容体ではない。
5. pSS唾液腺のFcRL4陽性B細胞は、導管上皮内・近傍、特にlymphoepithelial lesion（LEL）に集積し、耳下腺で小唾液腺より多い。PAX5陽性のB細胞で、15〜20%以上がKi-67陽性と報告され、CD11c、T-bet、TACI、CXCR3、CCR5、NF-κB関連遺伝子、IL6、cell-cycle/metabolic pathwayが上昇する。
6. このpSS phenotypeは「完全に疲弊して機能停止した細胞」とは合わない。最も妥当な表現は、**BCR-hyporesponsive/exhausted-likeでありながら、TLR・BAFF/APRIL・CD40・cytokine・上皮ニッチにより増殖・炎症機能を維持する、慢性活性化型のtissue/atypical memory B cell state**である。
7. pSSで増える主因は、BCR signalの強さではなく、CXCL10-CXCR3による導管へのrecruitment、CD11c/β2-integrin-ICAM1による局所保持、BAFF/APRIL-TACI-NF-κB、TLR ligand、T-cell help、および局所クローン増殖と考えられる。BCR抑制と細胞増加は矛盾しない。
8. 現時点では、pSS由来FcRL4陽性B細胞でFcRL4を直接knockdown/block/agonizeした機能研究は乏しい。FcRL4が病態を駆動する分子である証拠より、病態stateを同定するmarkerである証拠の方が強い。

## 1. 最初に分けるべき3つの概念

FcRL4を議論する時は、以下を混同しないことが重要である。

| 概念 | 何を意味するか | 現在の証拠 |
|---|---|---|
| FcRL4分子の機能 | FcRL4を発現・架橋した時にBCR/TLR signalがどう変わるか | B cell line、transfection、chimeric receptor、一次B細胞で比較的強い |
| FcRL4陽性B細胞の機能 | FcRL4を発現するcell state全体の増殖、抗体産生、cytokine、組織局在 | 正常扁桃、慢性感染、RA、pSS組織で強いが、FcRL4以外の分子も多数異なる |
| pSSでの因果 | FcRL4分子そのものがLEL、上皮傷害、リンパ腫化を起こすか | 未確立。局在・相関・除去後変化はあるが、FcRL4特異的perturbationが不足 |

FcRL4にはマウスの直接orthologがないため、通常の遺伝子欠損マウスで生理機能やpSS因果を検証しにくい。この点も、分子機能よりcell-state markerとしての証拠が先行している理由である。

## 2. 正常組織におけるFcRL4陽性B細胞

### 2.1 正常での局在

FcRL4陽性B細胞は、正常人では主に次の場所に存在する。

- 扁桃crypt epitheliumとperifollicular region。
- Peyer patchなどのintestinal lymphoid tissue。
- mesenteric lymph nodeなどのmucosa-associated lymphoid tissue。
- 上皮境界・submucosal/marginal zoneに近い領域。

骨髄、末梢血、脾臓では通常少ない。扁桃ではCD19陽性B細胞の約10%、IgD陰性CD38陰性memory compartmentの約3分の1という初期報告があり、多くはCD27陰性だった。

代表的phenotype:

- IgD低値/陰性、CD38陰性、CD20高値。
- CD27は陰性が多いが、全例ではない。
- CD69、CD80、CD86などのactivated phenotype。
- CD11c、CCR1、CCR5、CCR6が高く、組織・上皮近傍へ向かうhoming profile。
- FGR、HCK、LYN、SHP-1、複数のITIM receptorを発現。
- class switchingとsomatic hypermutationを経験した真正のmemory B cellだが、FcRL4陰性memory B cellよりmutationが少ないという後続報告もある。

一次文献:

- [Ehrhardt et al., J Exp Med 2005](https://pmc.ncbi.nlm.nih.gov/articles/PMC2212938/)
- [Ehrhardt et al., J Exp Med 2008](https://pmc.ncbi.nlm.nih.gov/articles/PMC2525601/)

### 2.2 BCR signalの抑制

FcRL4細胞内tailには3つの重要なtyrosine motifがあり、FcRL4はbasal状態でもリン酸化され、SHP-1/SHP-2と会合し得る。

実験的には次が示されている。

1. FcRL4 tailを用いたchimeric receptorをBCRと共架橋すると、BCR依存性Ca flux、全tyrosine phosphorylation、ERK/MAPK、Aktが強く抑制される。
2. intact FcRL4を発現させたB細胞では、BCR immune synapse形成が乱れ、Syk phosphorylation、PLCγ2、Vav、Ca flux、CD69 inductionが低下する。
3. FcRL4の3つのtyrosineとSHP-1/SHP-2 recruitmentがこの抑制に関わる。
4. 正常扁桃FcRL4陽性memory B細胞は、anti-IgによるBCR刺激やStaphylococcus aureus Cowan刺激では増殖しにくい。

したがって、FcRL4のBCR brakeとしての性質は比較的強い証拠がある。

- [Ehrhardt et al., PNAS 2003](https://pubmed.ncbi.nlm.nih.gov/14597715/)
- [Sohn et al., Blood 2011](https://pmc.ncbi.nlm.nih.gov/articles/PMC3236118/)

### 2.3 BCRを抑えても、B細胞全体を停止させるわけではない

正常扁桃FcRL4陽性B細胞は、BCR ligationには低反応でも、IL-2、IL-10、CD40Lなどには反応し、FcRL4陰性memory B cellより多くのimmunoglobulin-secreting cellを生じる条件があった。

つまりFcRL4陽性B細胞は、次のようなAND-gateに近い。

```text
BCR単独の抗原刺激
    → FcRL4/SHP-1/2 brakeにより増殖しにくい

TLR + CD40/T-cell cytokine + tissue survival signal
    → 増殖、抗体産生、cytokine産生が可能
```

この性質は、抗原とcommensalへの曝露が常にある粘膜境界で、BCRへの結合だけで過剰反応せず、danger signalやT-cell helpがそろった時に応答する仕組みとして合理的である。ただし、これは生理機能の有力モデルであり、ヒトin vivoで直接証明された目的論ではない。

### 2.4 TLR9応答の増強: adaptiveからinnateへのswitch

Sohnらは、FcRL4発現B細胞でCpG/TLR9刺激によるCD23 inductionが増強し、その強さがFcRL4発現量と相関することを示した。FcRL4とCpGはendosomal compartmentで共局在し、3つのcytoplasmic tyrosineが必要だった。

この結果から、FcRL4は次のswitchと解釈されている。

```text
抗原特異的BCR signal ↓
TLR9に代表されるinnate nucleic-acid signal ↑
```

注意点:

- FcRL4によるTLR増強の直接証拠はTLR9/CpGが中心である。
- TLR7でもFcRL4陽性cell subsetが強い反応を示す報告はあるが、FcRL4分子がTLR7を直接増強することはTLR9ほど確立していない。
- これらの中心実験はB cell line、FcRL4-transfected primary B cellであり、正常粘膜やpSS組織内で同じ強度のswitchが起きることは未確証である。

### 2.5 正常粘膜防御で何をしていると考えられるか

正常扁桃FcRL4陽性memory B cell由来抗体は、FcRL4陰性memory B cell由来抗体よりcommensal microbiota抗原への反応性が高かった。この反応は単なるpolyreactivityでは説明されなかった。

したがって生理機能としては、次の組合せが最も妥当である。

1. commensal・反復微生物抗原を記憶するmucosal memory pool。
2. BCR単独による過剰なclonal expansionをFcRL4で抑える。
3. microbial DNAなどのTLR ligand、CD40、T-cell cytokineがそろえばinnate-likeな局所応答を維持する。
4. 抗原量が多い粘膜で、過剰反応と防御反応の両方を調整する。

「外的ウイルスなどへの反応が過剰にならないようにする」という理解は一部妥当だが、次の修正が必要である。

- ウイルス特異的な仕組みではなく、commensal、細菌、ウイルス、慢性抗原刺激を含む広い粘膜環境への適応と考える。
- 全免疫反応を抑えるのではなく、BCR依存adaptive responseを抑え、TLR依存innate responseを温存・増強する。
- HIVなどの慢性感染ではFcRL4高発現tissue-like memory B cellが増え、ウイルス特異的B細胞がこの低反応性compartmentに偏る。これは防御的homeostasisを超えて、非効率な抗体応答につながるmaladaptive exhaustionになり得る。

- [Thompson et al., J Immunol 2018: commensal reactivity](https://pmc.ncbi.nlm.nih.gov/articles/PMC5988966/)
- [Moir et al., J Exp Med 2008: HIV-associated exhaustion](https://pmc.ncbi.nlm.nih.gov/articles/PMC2525604/)

### 2.6 IgA/J-chain receptorとしての機能

FcRL4はIgA receptorでもある。ただし現在の理解は、古い「粘膜IgA receptor」という表現より限定的である。

| Ig分子 | FcRL4結合 |
|---|---|
| J-chain-linked systemic dimeric IgA | 結合する |
| mucosal secretory IgA | secretory componentが立体障害となり、結合しにくい |
| J-chain-containing IgM | 2026年構造研究ではentropic penaltyにより識別 |

一次FcRL4陽性memory B cellはIgAでconstitutively occupiedされているとの報告がある。2026年cryo-EMではFcRL4:dIgA coreが1:1で結合し、主な接触相手はIgA FcそのものよりJ-chainだった。一方、FcRL4はIgA/IgA immune complexをinternalizeしなかった。

これはFcRL4が、IgA immune complexを貪食・回収する受容体というより、IgA/J-chain環境を感知してBCR thresholdを調整する受容体である可能性を支持する。ただし、IgA ligationが正常B細胞またはpSS B細胞のTLR/BCR/cytokineをどう変えるかは十分に解明されていない。

- [Liu et al., J Immunol 2020](https://pubmed.ncbi.nlm.nih.gov/32513851/)
- [Su et al., PNAS 2026](https://pubmed.ncbi.nlm.nih.gov/42308047/)

## 3. pSS病変組織におけるFcRL4陽性B細胞

### 3.1 どこに存在するか

pSSでは、FcRL4陽性B細胞は単に唾液腺浸潤B細胞全体に均等に存在するわけではない。

- 導管上皮内および導管近傍に集積する。
- LEL内のB細胞の大部分、場合によってはほぼ全てがFcRL4陽性。
- periductal infiltrateでは一部のみFcRL4陽性で、上皮に近い位置に多い。
- labial glandよりparotid glandで多い。
- pSS関連parotid MALT lymphomaでもFcRL4/IRTA1が発現し、非リンパ腫pSS耳下腺よりmRNAが高い。
- 血中FcRL4陽性B細胞はpSSで明確に増えず、組織局所性が強い。

Haackeらは、FcRL4陽性B細胞をrituximabで減らした時にLEL改善と上皮の部分的回復が起こり、abataceptでは同様の変化がなかったと報告した。ただしこれはFcRL4特異的治療ではなく、FcRL4陽性細胞を含むCD20陽性B細胞除去の結果である。

- [Haacke et al., J Autoimmun 2017](https://pubmed.ncbi.nlm.nih.gov/28390747/)

### 3.2 pSS FcRL4陽性B細胞のfunctional state

pSS耳下腺由来FcRL4陽性B細胞とFcRL4陰性B細胞のmini-bulk RNA-seqでは、FcRL4陽性群に次の特徴があった。

| 上昇する因子・pathway | 機能的解釈 |
|---|---|
| ITGAX/CD11c、TBX21/T-bet | chronically activated/atypical memory-like state、組織接着、IFN環境 |
| TNFRSF13B/TACI | epithelial/immune-cell由来BAFF・APRILへの感受性 |
| CXCR3、CCR5 | CXCL10などを介した炎症導管へのmigration |
| NFKB1、MAP3K14/NIK | canonical/non-canonical NF-κB activation |
| NFKBIA、NFKBID低下 | NF-κB抑制解除方向 |
| IL6 | 上皮過形成・局所炎症crosstalk候補 |
| Src-family kinase、cell-cycle、metabolic pathway | 慢性活性化と増殖可能性 |

さらに、病理学的にはintraductal FcRL4陽性B細胞の約15〜20%以上がKi-67陽性である。これは「BCRには鈍いが、組織内で増殖している」ことを示す。

- [Verstappen et al., J Autoimmun 2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7337041/)
- [Pringle et al., Front Immunol 2020: intraductal repertoire](https://pmc.ncbi.nlm.nih.gov/articles/PMC7372116/)

### 3.3 pSSで想定される病態機能

#### A. 導管上皮とのfeed-forward loop

```text
IFN-activated duct epithelium
  ├─ CXCL10 → CXCR3+ FcRL4+ B cellをrecruit
  ├─ BAFF/APRIL → TACI-high B cellを生存・活性化
  └─ ICAM1 ← CD11c/β2 integrinでB cellを保持

FcRL4+ B cell
  ├─ IL-6などの炎症性mediator
  ├─ antigen presentation / T-cell interaction候補
  └─ 上皮増殖・LEL維持
```

rituximab後にFcRL4陽性B細胞減少とLEL・上皮構造の改善が並行したことは、このloopにB細胞が必要であることを支持する。しかしFcRL4分子自身がloopの必須driverかは不明である。

#### B. BCR非依存的な慢性活性化

唾液腺内では、細胞傷害に由来する核酸、microbial products、immune complex、BAFF/APRIL、CD40L、IL-21、IFN環境などが存在し得る。FcRL4によりBCR responseが抑えられても、TLR7/9、TACI-NF-κB、CD40、cytokine signalingで細胞は生存・増殖・cytokine産生できる。

特に重要なのは、pSS intraductal B-cell repertoire解析で、導管内へのrecruitmentがBCR specificityで説明されなかった点である。IGHV sequenceの57%はclonal relationshipを持ち、導管内・導管周囲をまたぐcloneが存在した一方、RF-like BCRは導管内にenrichしていなかった。著者らはCXCR3-CXCL10によるrecruitmentを提案している。

したがって、FcRL4陽性B細胞が多いことを「自己抗原BCR signalが強いから増えた」と考える必要はない。

#### C. LELとMALT lymphoma precursor pool

FcRL4陽性B細胞は、LEL内で局所増殖し、clonal expansionを示し、pSS関連MALT lymphomaでもFcRL4発現が保たれる。慢性のTACI/NF-κB、TLR、IFN、上皮刺激下で長期生存することが、クローン選択やlymphomagenesisの土台になる可能性がある。

ただし次は未証明である。

- FcRL4がリンパ腫化を直接駆動する。
- 診断時labial glandのFcRL4陽性細胞数が将来のMALT lymphomaを予測する。
- FcRL4陽性細胞を除けばMALT lymphomaを予防できる。

## 4. なぜBCR抑制分子を持つFcRL4陽性B細胞がpSSで増えるのか

これは矛盾ではなく、cell expansionを決めるsignalがBCRだけではないためである。

### 4.1 FcRL4発現は慢性刺激の結果として誘導され得る

正常血中memory B cellをCD40LまたはCpG/ODNで刺激すると、分裂前の24時間以内にFcRL4発現が誘導されたin vitro研究がある。FcRL4は固定されたlineage markerだけではなく、CD40/TLRを含む持続刺激で誘導されるstate markerでもある。

このためpSSでは、慢性上皮炎症、TLR ligand、T-cell helpがFcRL4陽性stateを繰り返し作る可能性がある。

- [Jego et al., PLoS One 2017](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0179793)

### 4.2 CXCL10-CXCR3でBCR specificityと無関係に集まる

pSS導管上皮はCXCL10を産生し、FcRL4陽性B細胞はCXCR3を高発現する。従って、自己抗原をBCRで強く認識するcloneだけでなく、既にactivated/FcRL4/CXCR3-positiveとなったB細胞がchemokineで導管へ集積できる。

### 4.3 BAFF/APRIL-TACI、TLR、CD40がBCR brakeを迂回する

FcRL4陽性pSS B細胞はTACI、NF-κB1、NIKを高発現し、NF-κB negative regulatorを低下させる。導管上皮・炎症細胞が出すBAFF/APRIL、TLR ligand、CD40/T-cell cytokineは、BCRが弱くても生存・活性化を維持できる。

### 4.4 上皮接着と局所増殖で蓄積する

CD11c/β2 integrinとepithelial ICAM1の相互作用はFcRL4陽性B細胞を導管に保持し得る。15〜20%以上のKi-67陽性率とclonal expansionは、単なる受動的集積ではなく局所増殖を示す。

### 4.5 BCR brakeは、慢性刺激下で細胞を止めるのではなくsignal sourceを変える

FcRL4によりBCR signalが下がることで、細胞はadaptive antigen-specific proliferationより、TLR/TACI/CD40/cytokine依存の炎症stateへ偏る。従ってFcRL4は「抑制が強くなった細胞の印」ではあるが、その抑制はBCR branchに選択的であり、細胞全体の炎症機能を意味しない。

## 5. 「疲弊marker」という考察の評価

### 結論

**半分は正しいが、FcRL4を疲弊markerだけと定義するのは狭すぎる。**

| 観点 | pSS FcRL4陽性B細胞での評価 |
|---|---|
| BCR低応答 | 分子機序から強く予想される。ただしpSS fresh cellでの直接比較は不足 |
| 抑制受容体を多く持つ | 正常・HIV・in vitro FcRL4陽性cellで支持 |
| 増殖停止 | 当てはまらない。pSS腺内では15〜20%以上Ki-67陽性 |
| cytokine/NF-κB低下 | 当てはまらない。pSSでNF-κB/IL6/activation signatureが上昇 |
| plasma cell differentiation低下 | 正常/in vitroでは支持され、pSS FcRL4陽性cellはBLIMP1などplasma-cell markerに乏しい |
| 慢性抗原刺激の履歴 | 強く支持される |
| 病態組織へのhoming/retention | 強く支持される |

HIVのFCRL4-high tissue-like memory B cellは、低い増殖能、複数の抑制受容体、非効率なvirus-specific antibody responseを示し、「exhausted」と呼ぶ根拠がある。一方、正常扁桃FcRL4陽性cellはT-cell cytokineで抗体産生でき、pSS腺内FcRL4陽性cellはKi-67陽性・NF-κB/IL-6-highである。

従ってpSSでは、次の表現が最も正確である。

> FcRL4は、terminal exhaustionの単独markerではなく、慢性刺激を受けたBCR-hyporesponsive、innate-skewed、tissue-resident/atypical memory B-cell stateを示すmarker兼機能受容体である。

### FcRL4はmarkerかdriverか

現時点の重みづけ:

- **state markerとしての確度: 高い。** 正常粘膜、慢性感染、RA、pSSで一貫して慢性刺激・組織局在B cellを同定する。
- **BCR brakeとしてのdriver機能: 高い。** 細胞系と一次B細胞で直接機能実験がある。
- **TLR9 biasのdriver機能: 中。** transfection/細胞系で直接証拠があるが、pSS fresh cellで未検証。
- **pSS上皮傷害のdriver機能: 低〜中。** FcRL4陽性cellの局在、IL6、rituximab後上皮回復は整合するが、FcRL4特異的perturbationがない。
- **pSSでの増加を生むdriver機能: 低い。** FcRL4発現自体より、CXCL10、BAFF/APRIL、TLR、CD40、IFN、組織接着が上流と考える方が自然。

## 6. 統合モデル

```text
正常粘膜
commensal/反復抗原 + systemic dIgA/J + occasional TLR ligand
        ↓
FcRL4+ mucosal memory B cell
        ├─ FcRL4/SHP-1/2 → BCR overreactionを抑制
        └─ TLR9/CD40/cytokine → 必要時のinnate-like局所応答

pSS唾液腺
上皮damage/IFN/CXCL10 + nucleic acid/TLR ligand + BAFF/APRIL + T-cell help
        ↓
FcRL4/CXCR3/CD11c/T-bet/TACI-high stateの誘導・recruitment
        ↓
導管内保持 + local proliferation
        ├─ BCR branchは抑制的
        ├─ TLR/TACI/NF-κB/IL-6 branchは活性
        └─ LEL維持、上皮変化、長期的clonal selection/MALT risk
```

pSSは、正常粘膜で一時的・限定的に働くadaptive-to-innate switchが、慢性上皮炎症とsurvival signalにより固定・増幅された状態、と考えると最も矛盾が少ない。

## 7. このモデルを検証するための実験

### 7.1 fresh pSS組織でBCRとTLRを直接比較する

parotid gland由来FcRL4陽性/陰性B細胞をsortし、次を比較する。

- anti-Ig/BCR: pSyk、pBLNK、pPLCγ2、Ca flux、ERK、CD69。
- TLR9/CpG、TLR7/R848: p65、NIK、IRF7、CD23、CD80/CD86、IL-6、TNF、IFN-related genes。
- BCR + TLR7/9 combined signal。
- BAFF、APRIL、CD40L、IL-21追加時の生存、増殖、Ig産生。

予測は、FcRL4陽性群でBCR readout低下、TLR/TACI/cytokine readout維持または増強である。

### 7.2 FcRL4がmarkerかdriverかを分ける

同一のfresh pSS FcRL4陽性B細胞で以下を比較する。

1. FcRL4 knockdown/CRISPRi。
2. FcRL4-blocking抗体。
3. IgA非競合・Fc-silent anti-FcRL4。
4. agonistic/crosslinking anti-FcRL4。
5. isotype control。

FcRL4を消すだけでBCRが回復し、TLR9/NF-κBが低下すればdriver性が強い。FcRL4を変えてもphenotypeが維持されれば、CXCL10/BAFF/TLR/IFNが作るstate markerとしての性格が強い。

### 7.3 ligandの意味を確認する

- recombinant systemic dIgA1/J、dIgA2/J、monomeric IgA、secretory IgAを比較。
- FcRL4 occupancy、phosphorylation、SHP-1/SHP-2 recruitmentを測定。
- BCR/TLR9/TLR7/TACI signalへの影響を測定。
- pSS血清・唾液のIgA/J-chain complexがFcRL4に結合するかを確認。

唾液中secretory IgAがそのままligandだと仮定してはいけない。

### 7.4 pSSで増える過程をspatialに追う

- periductalからintraductalへのclone共有をBCR sequencingで追う。
- FcRL4、CXCR3、CXCL10、CD11c、ICAM1、TACI、BAFF/APRIL、Ki-67をspatial multiplexで測定。
- early pSS、LEL-low、LEL-high、MALTで連続性を確認。

## 8. 創薬上の意味

### 8.1 FcRL4 agonistによるBCR抑制だけを狙う場合

理論上はBCR brakeを強められるが、pSSでは既にBCR branchが低反応で、病態がTLR/TACI/NF-κB側に移っている可能性がある。さらにFcRL4 ligation/発現がTLR9応答を強めるなら、BCR readoutだけを見てagonistを選ぶと逆活性化の危険がある。

最低限、BCR Ca/pSykと同時にTLR7/9-NF-κB、IL-6、CD86、Ig産生を測定する必要がある。

### 8.2 FcRL4陽性cellの除去を狙う場合

Fc-active anti-FcRL4またはFcRL4×CD3 TCEは、FcRL4がdriverかmarkerかに依存せず、FcRL4陽性病態state全体を除去できる。そのため機序的にはagonistよりrobustである。

ただし、正常粘膜のcommensal-reactive memory B cellも除去する可能性がある。特に扁桃・腸管・気道での局所防御、IgA関連memory、感染歴を評価する必要がある。

### 8.3 anchorとして使う場合

FcRL4を病態B細胞の住所として使うなら、IgA/J-chain bindingを阻害しにくいnon-blocking epitopeが第一候補になる。FcRL4 moleculeの機能を不用意に変えず、FcRL4陽性cellへCD22 brakeまたはdepletionを届ける設計が可能である。

## 9. 最終結論

正常組織のFcRL4は、粘膜境界のmemory B cellに選択的に発現し、BCRによるadaptive responseをSHP-1/SHP-2で抑える一方、TLR9、CD40、T-cell cytokineを介するinnate-like responseを許容・増強する調節受容体である。外来抗原への過剰反応を防ぐ役割は妥当な仮説だが、ウイルス専用ではなく、commensalと反復微生物刺激を含む粘膜homeostasisのgateと考える方が正確である。

pSSでは、この正常なadaptive-to-innate switchを持つB cell stateが、CXCL10-CXCR3によるrecruitment、BAFF/APRIL-TACI-NF-κB、TLR ligand、CD40/cytokine、上皮接着により導管内に蓄積・増殖する。従ってBCR抑制とFcRL4陽性B細胞増加は矛盾しない。

「FcRL4は疲弊markerではないか」という考察は、BCR低応答と慢性刺激履歴を表す点では正しい。しかしpSS細胞は増殖性・炎症性を保つため、terminal exhaustionというより、**BCR-hyporesponsive、innate-skewed、chronically activated tissue B-cell stateのmarker兼調節受容体**と定義するのが最も妥当である。
