# 既存治療で対応できない作用とFcRL4標的化の役割

作成日: 2026-08-20
対象宿題: 3. 既存治療で対応できない作用とFcRL4標的化の役割

## 一言メッセージ

抗CD20、抗CD19、BAFF/APRIL阻害はB細胞全体を減らす、または生存シグナルを弱める治療だが、FcRL4標的化は「粘膜上皮・唾液腺・滑膜に埋め込まれた病態局所B細胞」を選んで制御するためのアプローチである。

## 既存治療で十分に対応できていない細胞集団

### 1. 唾液腺上皮近傍のFcRL4+組織メモリーB細胞

pSSでは、FcRL4+ B細胞が導管上皮近傍やリンパ上皮病変で観察される。これらは血中B細胞とは異なり、腺局所の構造に埋め込まれている可能性が高い。抗CD20で末梢B細胞を枯渇しても、pSS症状改善が一貫しない理由の一部として、局所ニッチの制御不足が考えられる。

作用仮説:

- FcRL4 x CD22でFcRL4+ B細胞のBCR/活性化シグナルを抑制し、腺上皮との炎症ループを弱める。
- FcRL4 x CD3でFcRL4高発現細胞を短期的に除去し、リンパ上皮病変またはMALTリスクの高い局所B細胞をリセットする。
- 抗FcRL4単独抗体で、まず組織染色・標的占有・細胞数変化を確認する探索的治療/診断ツールにする。

### 2. MALTリンパ腫またはMALTリンパ腫前駆様のIRTA1/FcRL4+ B細胞

IRTA1/FcRL4はMALTの上皮近傍B細胞とmarginal zone lymphomaで報告されている。pSSではMALTリンパ腫リスクが臨床的問題になるため、FcRL4+ B細胞は「腺病変」と「リンパ腫化リスク」をまたぐサブセットとして位置づけられる。

作用仮説:

- FcRL4高発現かつクローン性/LEL陽性の患者を選び、FcRL4 x CD3またはFc活性型抗FcRL4で選択的に除去する。
- FcRL4 x CD22は、悪性化前の慢性活性化B細胞を殺さずに鎮める設計として検討できる。

注意点:

- MALTリンパ腫でFcRL4/IRTA1が全例陽性ではない。部位差があるため、治療標的としてはFcRL4 IHC/RNA-ISH陽性患者に絞る必要がある。

### 3. RA滑膜のRANKL/TNF産生FcRL4+ B細胞

RAではFcRL4+ B細胞が滑膜で増え、RANKL/TNF、破骨細胞分化、シトルリン化自己抗原反応性と結びつく。抗CD20はRAで効果があるが、全身B細胞枯渇であり、滑膜局所のFcRL4+病態B細胞を選ぶものではない。

作用仮説:

- FcRL4 x CD22で滑膜FcRL4+ B細胞の活性化を抑え、TNF/RANKL産生や抗原提示を弱める。
- FcRL4 x CD3は難治性・組織FcRL4高発現のRAサブセットで、局所B細胞除去を狙う。

### 4. IgA/粘膜由来の自己反応性B細胞

FcRL4はJ-chain含有全身性IgAを認識する。RAではFcRL4+ B細胞由来抗体にIgA使用やシトルリン化抗原反応性が示されている。pSSでも腺・粘膜局所の免疫異常が中心であることから、FcRL4はIgA/粘膜免疫と自己免疫をつなぐ標的として説明できる。

ただし、FcRL4-IgA結合が病態を直接進めるかは不明。現時点では、IgA軸は「標的細胞の生物学的特徴」として使い、薬理の主軸はFcRL4+病態B細胞の選択的制御に置くのがよい。

## 既存治療との比較で使える説明

### 抗CD20との差別化

抗CD20は「B細胞を広く減らす」治療。pSSでは末梢B細胞や一部組織B細胞には作用するが、大規模RCTの症状改善は一貫しない。一方、FcRL4標的化は、pSSの導管上皮近傍/リンパ上皮病変にいるB細胞を標的にするため、腺局所病変に対する仮説が立てやすい。

### 抗CD19との差別化

抗CD19はCD20より広く、形質芽細胞の一部まで狙える点で強い。しかし、その強さは全身B細胞枯渇の強さでもある。FcRL4は「どのB細胞を狙うか」を指定する標的であり、CD19のような広範枯渇と対比して、病態局所選択性を打ち出せる。

### BAFF/APRIL阻害との差別化

BAFF/APRIL阻害はB細胞の生存・分化シグナルを下げる治療であり、全身性自己免疫では理にかなう。ただし、pSSの唾液腺局所に成立した上皮近傍メモリーBニッチを直接消す治療ではない。FcRL4は、局所ニッチにいる細胞そのものを抑制/除去する設計にできる。

### Obexelimab/CD19 x FcγRIIBとの差別化

ObexelimabはCD19陽性B細胞全体にFcγRIIB抑制シグナルを入れる設計。一方、FcRL4 x CD22は、CD19全体ではなくFcRL4+病態局所B細胞を入口にする設計であり、抑制シグナルを入れる相手をより絞れる。差別化の本質は「抑制受容体の違い」よりも「標的B細胞の絞り込み」にある。
