# Proposal 2 追加調査: FcRL4標的の腺外症状への影響と他疾患展開

作成日: 2026-07-12

対象は `FCRL4 x CD22 組織B細胞サイレンサー` である。このメモでは、Sjögren病でFcRL4+ B細胞に絞った場合に、乾燥/腺症状以外の関節痛、神経障害、皮膚、肺、腎、疲労などへどこまで影響しうるかを整理する。さらに、FcRL4を起点に他疾患へ展開できるかを評価する。

## 結論
FcRL4+ B細胞を標的にした時に最も効きやすいのは、唾液腺/涙腺/粘膜関連リンパ組織のB細胞ニッチに近い症状である。腺外症状への効果は一枚岩ではない。

最も期待できる腺外症状は、B細胞高活動性、RF/cryoglobulin、低C4、高IgG、CXCL13/Tfh、リンパ腫リスクと連動する患者群である。一方、疲労、慢性疼痛、線維筋痛症様症状、不可逆な神経障害は、FcRL4+ B細胞を抑えても動きにくい可能性が高い。

他疾患展開では、最有力は関節リウマチである。RA滑膜ではFcRL4+ B細胞がRANKL/TNF高発現の炎症性B細胞として報告され、FcRL4+ B細胞由来抗体がシトルリン化自己抗原反応性を示す報告もある。これは、FcRL4 x CD22の「組織B細胞dual brake」という考え方を、Sjögren腺内B細胞からRA滑膜B細胞へ展開できる可能性を示す。

## 腺外症状に効く患者像
FcRL4+ B細胞標的で腺外症状まで狙うなら、乾燥症状だけの患者ではなく、次のようなB-cell-high/systemic-high segmentを選ぶ。

| 患者選択軸 | 理由 |
|---|---|
| 唾液腺FcRL4+ B細胞高値 | 標的が存在することが最初の条件。 |
| CXCL13高値、Tfh/Tph signature | 腺内B細胞ニッチと全身B細胞高活動性をつなぐ可能性。 |
| RF陽性、IgA/RF、cryoglobulin | 免疫複合体性腺外症状とFcRL4/IgA biologyをつなぐ候補。 |
| 低C4、高IgG、形質芽細胞高値 | B細胞高活動性のsystemic readout。 |
| 腺腫脹、MALT lymphoma risk marker | FcRL4+ B細胞ニッチの臨床的強さ。 |
| 関節炎なら滑膜炎画像陽性 | 単なる痛みではなく組織炎症を伴うことを確認。 |
| 神経障害ならvasculitic/cryoglobulinemic phenotype | FcRL4標的で動きうるB細胞-免疫複合体病態に絞る。 |

## 腺外症状でのGo/No-Go
| 判定 | 条件 |
|---|---|
| Go | 唾液腺FcRL4+ B細胞量が高く、血中CXCL13/RF/cryoglobulin/低C4/高IgGと連動し、ex vivoでFcRL4 x CD22がIg産生、抗原提示、Tfh help、BCR/TLR応答を抑える。 |
| Conditional Go | 腺症状は動くが腺外症状biomarkerとの連動が弱い。適応はgland B-cell-high Sjögrenに限定し、腺外症状改善はsecondary endpointにする。 |
| No-Go | FcRL4+ B細胞が腺内にいても、関節/神経/皮膚/腎/肺の病勢やB細胞高活動性指標と無関係。 |
| No-Go | FCRL4 ligationでTLR7/9、CD40、IL-21、Ig産生、CD86/HLA-DRが増える。 |

## RA展開案
RAで考える場合、Sjögrenと同じ `FCRL4 x CD22` をそのまま使うのではなく、滑膜FcRL4+ B細胞の機能を見てから設計を選ぶ。

| 設計 | RAでの狙い |
|---|---|
| Fc-silent FCRL4 x CD22 | FcRL4+滑膜B細胞のBCR/TLR/Tfh反応を沈静化する。 |
| FCRL4 x FCGR2B | CD22より強い抑制co-receptor benchmark。obexelimab型との差別化が課題。 |
| FCRL4 x RANKL blocking | FcRL4+RANKL+ B細胞の骨破壊寄与を局所的に抑える。ただしBsAb必然性は要検証。 |
| Fc-active/Fc-tuned FCRL4 | RANKL/TNF高発現の滑膜B細胞を局所modulation/depletion。ただしRAでは安全域と競合が厳しい。 |

RAでの初期PoCは、滑膜液/滑膜生検でFcRL4+CD22+ B細胞、RANKL、TNF、IgA、ACPA反応性、BCR/TLR応答を同時に見る。血液だけでは進めない。

## 開発上の修正
提案2の主適応は引き続き `gland B-cell-high Sjögren病` とする。ただし、効能の言い方は変える。

避ける言い方:

```text
FcRL4+ B細胞を抑えれば、Sjögrenの全身症状にも広く効く。
```

推奨する言い方:

```text
FcRL4 x CD22は、唾液腺/粘膜B細胞ニッチを起点とするSjögren病に最も適している。
腺外症状は、RF/cryoglobulin/低C4/CXCL13などB-cell-high systemic axisに連動する患者でのみ狙う。
関節や神経症状はprimary endpointではなく、機序層別したsecondary endpointとして扱う。
```
