# 関節リウマチ: FcRL4横展開候補

## 位置付け
関節リウマチは、元の自己免疫B細胞シーズ探索10疾患には含めていなかったが、FcRL4を起点に見ると最も重要な横展開候補である。

## B細胞病態の根拠
RAでは滑膜内B細胞、自己抗体、ACPA、RF、異所性リンパ組織、Tfh/Tph様ヘルプが病態に関与する。FcRL4+ B細胞はRA滑膜液/滑膜組織に報告され、RANKLやTNFを高発現する炎症性B細胞subsetとして位置付けられている。

さらに、RA滑膜FcRL4+ B細胞由来抗体がシトルリン化自己抗原に反応する報告があり、FcRL4+ B細胞が単なる組織resident markerではなく、局所自己免疫応答に参加している可能性がある。

## 未充足ニーズ
TNF、IL-6R、CTLA4-Ig、JAK、CD20など多数の治療があるが、難治性RA、滑膜B細胞高値、骨破壊進行、自己抗体高値の患者が残る。

## 抗体での介入しやすさ
中。滑膜FcRL4+ B細胞がCD22を保っており、BCR/TLR/Tfh helpに反応するなら、FCRL4 x CD22またはFCRL4 x FCGR2Bで組織B細胞silencingを狙える。

## 標的候補
FCRL4、CD22、FCGR2B、RANKL、CD20、CD19、CXCL13、IL21R。

## モダリティ仮説
| モダリティ | 仮説 |
|---|---|
| Fc-silent FCRL4 x CD22 BsAb | FcRL4+滑膜B細胞にCD22 brakeを入れ、BCR/TLR/RANKL/TNFを抑える。 |
| FCRL4 x FCGR2B BsAb | より強い抑制受容体co-ligation。ただしobexelimab型との差別化が必要。 |
| FCRL4 x RANKL blocking BsAb | FcRL4+RANKL+ B細胞の骨破壊寄与を局所的に抑える仮説。 |
| Fc-active/Fc-tuned anti-FCRL4 | 滑膜FcRL4+炎症性B細胞をmodulation/depletionする。安全性と競合が重い。 |

## 患者選択バイオマーカー
滑膜FcRL4+CD22+ B細胞、滑膜RANKL/TNF、ACPA、RF、IgA ACPA、CXCL13、滑膜B-cell-rich pathotype、超音波/MRI滑膜炎。

## 競合密度
高い。RA全体では過密であるため、一般RAではなく、滑膜B-cell-rich、FcRL4+RANKL+、難治性、骨破壊進行segmentに限定する必要がある。

## 革新的シーズ仮説
Sjögrenでの `FCRL4 x CD22 組織B細胞サイレンサー` を、RAでは `滑膜FcRL4+ B細胞サイレンサー` として横展開する。血液ではなく滑膜組織B細胞を標的にする点が差別化である。

## 最初の検証
1. RA滑膜液/滑膜生検でFcRL4+CD22+ B細胞の頻度を確認。
2. FcRL4+ B細胞のRANKL、TNF、IL-6、CD80/CD86、HLA-DR、ACPA反応性を測る。
3. anti-CD22単独、anti-FCRL4単独、2剤併用、FCRL4 x CD22 Fc-silent BsAbを比較。
4. pSyk、pBLNK、pPLCγ2、Ca flux、TLR7/9、CD40、IL-21応答を測る。
5. 既存薬benchmarkとしてrituximab、abatacept、JAK阻害、TNF/IL-6R阻害後の残存FcRL4+ B細胞を見る。

## 不明点
RAでは競合が非常に多く、FcRL4+ B細胞を狙う臨床的必然性を示すには、滑膜FcRL4+ B細胞が難治性や骨破壊進行と強く結びつく必要がある。pSSと同じFCRL4 x CD22 geometryがRAでも最適かは不明。
