# Seed Proposal 2: IL-36-high皮膚炎症サブセット向けIL-36R抗体

## 1文での提案

Hidradenitis suppurativaや好中球性/上皮炎症性皮膚疾患のIL-36-highサブセットに対し、IL-36Rを遮断するFc-silent抗体を提案する。

## 疾患の壁

- HSは疼痛、排膿、瘻孔、瘢痕、再発を伴い、生活の質への影響が大きい。
- TNF阻害薬やIL-17阻害薬があっても、非奏効、部分奏効、瘻孔・瘢痕病変の残存が課題。
- HSは病態が多様で、炎症性結節、瘻孔、瘢痕、微生物、好中球炎症が混在する。

## 標的の妥当性

- IL-36R/IL1RL2は膜型サイトカイン受容体で、上皮炎症と好中球性炎症に関与する。
- SpesolimabによりIL-36R blockadeはGPPでdrugged targetとして成立している。
- ただし、GPPでの成功をHSや自己免疫皮膚疾患へそのまま外挿することはできない。

## 抗体である必然性

- IL-36Rは細胞表面受容体であり、抗体によるリガンド阻害が直接的。
- IL-36α/β/γの複数リガンドを受容体側でまとめて遮断できる。
- 慢性皮膚疾患ではFc effectorは不要であり、Fc-silent化によって安全性を優先できる。

## 抗体設計案

- 主案: Fc-silent blocking antibody
  - IL-36Rリガンド結合または受容体活性化を阻害し、ADCC/CDCを避ける。
- 条件付き案: Masked blocking antibody
  - 炎症皮膚局所で活性化できる場合のみ、全身安全性差別化として検討。
- 条件付き案: Bispecific antibody
  - IL-36R単独で弱い場合に、IL-17/TNF/IL-1系との二重遮断を検討。ただしCMCと安全性が重くなる。

## 既存薬との差別化

- TNF/IL-17阻害薬とは異なる、上皮-自然免疫-好中球炎症軸を狙う。
- GPP向けIL-36R薬とは、HSや自己免疫皮膚疾患のIL-36-highサブセットを選ぶ点で差別化する。
- 患者選択をlesional biomarkerベースにできれば、all-comer皮膚疾患開発より提案価値が上がる。

## 主要リスク

- HSの主要ドライバーがIL-36ではない可能性。
- IL-36発現が高くても、治療反応を予測しない可能性。
- TNF、IL-17、IL-1、IL-23、微生物、瘻孔/瘢痕構造による冗長性。
- 慢性IL-36R blockadeによる感染、皮膚バリア、上皮防御への影響。

## 最初にやるべき検証実験

1. HS病変皮膚と対照皮膚でIL36A/B/G、IL1RL2、好中球/keratinocyte signatureを比較する。
2. HS lesion explantでIL-36R阻害によりIL-8、CXCL1、好中球関連因子、keratinocyte activationが低下するか確認する。
3. TNF阻害、IL-17阻害とのex vivo比較を行い、IL-36R固有の作用を確認する。
4. Fc-silent抗体でFcγR/C1q陰性、正常keratinocyte毒性なし、長期刺激時のbarrier readoutを確認する。

## Go / No-Go基準

| 判定 | 基準 |
|---|---|
| Go | HSまたは関連皮膚疾患にIL-36-highサブセットが明確に存在する。 |
| Go | IL-36R blockadeが患者病変ex vivoでTNF/IL-17阻害と異なる炎症readoutを抑える。 |
| Go | 患者選択に使えるlesional biomarker候補がある。 |
| No-Go | IL-36 pathway発現が低い、または発現しても機能阻害でreadoutが動かない。 |
| No-Go | TNF/IL-17阻害と同質で、差別化が見えない。 |
| No-Go | 皮膚バリア、防御応答、感染関連readoutに許容しにくい悪化が出る。 |
